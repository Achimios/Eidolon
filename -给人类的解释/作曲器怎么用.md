# 作曲器怎么用（HTML 版，2026-10-26）

> 一件能玩的乐器，不是打谱机。你不用会钢琴：键盘锁在调里，按哪个都不会错音；吸附、力度这些「整理」在变体里挑。
> 设计见 `_设计/设计_作曲器.md` §四½；代码在 `tools/composer_web/`。

## 最近改了什么（2026-10-28，等你想玩的时候看这几行就够）
- 用真人声（原曲人声分轨）和代码审查、浏览器测试把作曲器从头测了一遍，修了 70 多处：录音不会再丢、抢拍的音不会变成「咔」一下、哼唱分析不卡音乐、撤销不会把作品 / 延迟 / 试听的音色弄乱。
- 新的录音规矩见下面「录音的规矩」；还没解决的见「已知局限」。
- 用法没变：双击 `start_composer.bat`，戴耳机，先「校准延迟」。

## 打开
双击 `tools/composer_web/start_composer.bat`（或 `.venv/Scripts/python.exe tools/composer_web/serve.py`），浏览器会打开 `http://127.0.0.1:8765/`。点一下「开始」。
- **戴耳机**：哼唱时伴奏漏进麦克风，会被当成你的声音。
- 用 Chrome / Edge。页面里的声音只是**预览**；最终音质由 Python 读 `作曲.json` 渲染。
- 网址后面加 `?silent=1` = 静音模式（一切照常运行、不出声），给自动测试用。

## 四种玩法
| 玩法 | 怎么做 | 记下什么 |
|---|---|---|
| **锁调键盘** | A 排 = 当前调的音阶，Q 排高八度，Z 排低八度（给贝斯）；↑↓ 换八度 | 每个音按下 / 松开的时刻、音高 |
| **拍** | Tab 切到「拍」：任意字母键拍一下，音高自动填当前和弦的音（默认越靠右越高） | 起音时刻 |
| **哼唱** | 选「哼唱」层 → 开麦 → 按 `（1 左边那个键）录：循环每转一遍存一条 | 原始录音 wav + 识别出的音符（含滑音 / 颤音的音高曲线） |
| **XY 推子** | 右边那块，拖 = 同时拧两个旋钮（默认 x = 截止、y = 失真）；录音时记成曲线。曲线（含张力）也能在时间线下方直接画 | 旋钮曲线（逐帧） |

鼓层：A 底鼓 · S 军鼓 · D 拍手 · F 闭镲 · G 开镲 · H 边击 · J 通鼓 · K 冲击（Q 排更重）。琶音层：播放中按住一个键 = 每个 1/16 自动弹一个和弦音。

## 循环、叠录、挑
1. 空格播放；循环一直转（默认 4 小节，顶栏改）。
2. 按 ` 录音：先数一小节（预备拍），然后边转边叠；再按 ` 停。每转一圈可以单独撤销（Ctrl+Z）。
3. 停了以后弹出 **4 个变体**：原样 / 吸附 60%（留人味）/ 吸附 100% / 第四个（有原曲鼓轨时 = 吸到原曲律动）。←→ 试听，Enter 用这个，Shift+Enter 叠成一条新层，Esc 放弃。「再来一组」换另外 3 种（摇摆、稀疏、八度叠、三度和声、连奏、断奏、强拍吸和弦音、规则力度……），「音色变体」换音色。
4. 哼唱录了几遍 → 在几遍里挑；只录一遍 → 挑「怎么理解它」（只取半音 / 吸到调 / 再吸节拍）。
- **原始演奏永远原样存着**（真值里的 `raw`），吸附只是「解释」，可以撤、可以换。
- 你按得稳定地早或晚，页面会说「你平均提前 23 ms」：那多半是延迟，吸附时已经扣掉。

## 哼唱识别做了什么
- 自动猜你在：**哼唱**（要音符，切得狠）/ **人声**（有词，要原声，辅音不算断）/ **旋律**（口哨，音高要准）。猜错了在左边「类型」里改，点「重新识别」。
- 整体唱高唱低（跑调）会先测出来、扣掉再吸附；进音的滑音、颤音不会被切成好几个音，但会作为音高曲线留在真值里（画面可以用）。
- 「校准延迟」：用哪副耳机哼唱，就把那副耳机贴着麦克风，页面放 6 下咔哒，自己测往返延迟（换耳机要重新校准）。
- 哼唱的分析在后台线程里算，不会卡住正在放的音乐。

## 录音的规矩（2026-10-27）
- 录音锁在**开始录时选中的那一层**：中途按数字键换层只换显示，不换录到哪。
- 录音中不能挪循环区、改速度、改全曲长度、换作品：要改先停。
- 开着循环录：抢拍（循环开头前一点点按下）的音记在循环尾巴，循环转回来时正好在开头前响；吸附时落到循环终点的会绕回循环开头；按住跨过循环尾巴的长音截在尾巴（不拆成两段）。
- 关着循环录：从开始录到停是一条；哼唱最长 10 分钟，到点自动停（这一条会存下）。预备拍里早于开始半拍以上的不记。
- 挑哪一遍：正在放的时候，人声和音符一起到下一遍循环开头才换。
- 「打开…」别的会话前，有没存的录音会先问你；打开以后撤销记录清空。

## 已知局限（2026-10-27）
- 哼唱识别用真人声测过一轮，但用的是从原曲分离出来的「唱」的人声分轨（加 Cortana 干声）对比 crepe，**不是哼唱**。你自己的哼唱样本（哼「嗯」、唱一句带词的、吹口哨）到了还要再测一次。实测：音高粗大错误约 8–10%、细节误差约 5 音分；人声模式漏掉整句 3/32（都是 ≤ 0.25 s 的短句）。
- 八度跳、小七度跳这种大跳，前几帧可能被当成八度误判折回去，跳音大约晚 30 ms 才被认出来；真人声逐帧八度错误约 6%。
- 唱偏 40 音分以上又带宽颤音（超过约 ±30 音分）时，不扣跑调，可能吸到隔壁的半音。
- 录音开头之前就唱出的强拍：起音会被切掉，音放在录音开头。
- 戴着蓝牙耳机延迟大（150–250 ms）：要戴着那副耳机校准，不然吸附会提示「偏了将近半格」，也不会替你扣掉。琶音在大延迟下按下那一刻可能一次响两个音。
- 改速度：键盘 / 拍的音跟着格子走；哼唱的音跟着录音（秒）走，会离开新的格子。
- 范围删除 / 复制只管音符和曲线，录音和分轨的声音不剪。拖进来超过 90 s 的文件不随会话存（长伴奏请放进作品的 `分轨/` 再「载入原曲分轨」）。
- 真值里的 `audible` 是保存那一刻按「静音 + 场景」算的快照（独奏不算）。
- 没有 MIDI 设备支持；页面里的声音只是预览。

## 层、场景、时间线
- 左边：层（数字键选）、M 静音 / S 独奏 / ✕ 删（可撤），下面是这一层的旋钮，名字用合成器词表的 15 个词。
- 底下时间线：拖音符 = 移（上下 = 调内走一级，按住 Alt 不吸附）；空白处拖 = 框选；双击空白 = 加音；标尺上半条拖 = 设循环区，下半条拖 = 选一段；Ctrl+C / V / D 复制 / 粘贴到光标 / 复制一份到后面；Delete 删。Ctrl+滚轮缩放，Shift+滚轮平移。编辑吸附选「自由」= 完全不吸。
- 场景：「在循环起点加场景」= 从这个小节起只有勾上的层在响；每个场景可以写一句「她此刻」（进真值的 `mood`）。Shift+数字跳过去。场景建好以后再加的层会自动加入所有场景。
- 五声音阶下拍、琶音、吸和弦音也只出调内的音。
- 「载入原曲分轨」：读作品的 `分轨/`，按顶栏的「起点」切那一段当伴奏；先在「原曲从第几小节开始」里选一个重拍。也可以直接把 wav 拖进页面。

## 存在哪
「保存」（Ctrl+S）→ `Projekt_Visual/<作品>/作曲/`：
- `作曲_vN.json`：**真值**（画面、感受器、Python 渲染读它）。时间一律是歌曲播放时间（秒）。
- `作曲_vN_会话.json`：能接着玩的那份（「打开…」读回来）。
- `哼唱_vN_第K遍.wav`：原始录音（24 bit）。
- 每次存都是新版本号，**绝不覆盖**。浏览器自己也会记住音符和设置，但录音只在「保存」以后才在硬盘上。
- **定稿**：觉得这一版可以了就点「定稿」，它会写 `作曲/当前.txt`（一行：`作曲_vN.json`）。感受器、剪辑、画面**只读这一版**；没定稿就不用作曲真值。改过还没存的话，会先存一版再定。随时可以再定别的版本，每次定稿都记在 `定稿记录.txt` 里。
- 出无损音频：`python tools/composer_render.py <作品>/作曲/作曲_vN.json` → `作曲/渲染_vN/`（混音 −14 LUFS + 每层分轨 + 报告）。
