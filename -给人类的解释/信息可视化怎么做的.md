# 信息可视化怎么做的（`tools/info_graph.py`）

> 参考：`Projekt_Visual/_参考库/信息可视化_节点坐标.gif`、`AI Strategy.mp4`（+ MACHINE BEHAVIOR 的版式）。拆解：`_参考库/分析_信息可视化/分析.md`。
> 👤：「这个效果很有用，因为信息量巨大！I just love graphic with info, not just fancy decorations」
> ⭐判据：**符号说真话** —— 画面上每个点、每条线、每个数字都能对回一份真实数据；没有一个是为了好看编的。

## 一句话
参考片的「语法」是：**点 = 被检测到的东西，框 = 它真实的包围盒，线 = 它们之间的某种关系，小字 = 它的真实坐标**；画面靠「只有 3 种图元、字又小又暗、黑底占大半」不乱，靠「冲击时信息最多、安静时只剩一个点」有节奏。我们把这套语法套到两种真数据上。

## A 版：记忆图谱 —— 06「一个名字」（1:55.51–2:08.31）
**故事**：狂语之后，她在自己的记忆里找一样东西。找遍了，最后找到的是 John。

| 画面上的东西 | 它是什么（真数据） |
|---|---|
| 每个小方框 / 缩略图 | 剪辑表 `剪辑表_v4_0-97.txt` 里的一个镜头（= 到 06 为止她「经历过」的画面），缩略图 = 那个镜头中间那一帧的真实画面 |
| 节点的位置 | 这个镜头那段时间里，感官五个通道的平均值（心跳 β、威胁 θ、饥饿 η、张力 τ、每秒起音数 ρ），标准化后做 **PCA**（主成分分析）投到两维。坐标轴上写着两根轴分别由哪几个通道组成（载荷）和各占多少方差 —— 位置本身就是信息：离得近 = 那两段音乐「感觉」像 |

| 细实线 | 故事线：剪辑顺序上相邻的两个镜头 |

| 点线 | 回想：同一段素材在剪辑表里再次出现，连回上一次 |

镜头：开场已经在高速平移（从「最早的记忆」那一侧扫向「此刻」，先快后慢）；之后每弹出一个节点，相机用临界阻尼弹簧追过去（= 一次「进」一次「缓」）；找到 John 后 2.5 s 拉远到能看见整条路径。整段不停。

### 她是怎么「找」的 —— 搜索算法的直觉版（2026-10-23 补）

**一句话**：像一滴墨从「此刻」滴进水里，沿着记忆之间的线慢慢洇开；哪段记忆先被洇到，就先被想起。这个算法叫 **Dijkstra 最短路**（1956 年，荷兰人 Edsger Dijkstra 据说在咖啡馆里二十分钟想出来的）。

**分三步看：**
1. **每段记忆是一个点，点上记着「那时的感觉」。** 不是画面内容，而是那段音乐让人什么感觉：心跳、威胁、饥饿、张力、起音密度 —— 五个数（感官层算的，标准化后单位是「比平时高几个标准差」）。
2. **记忆之间连线，线的长度 = 两段感觉差多远。** 三种线：
   - 故事线：剪辑里前后挨着的两个镜头（经历的先后）；
   - 情绪近邻：五维感觉里最像的 3 个（「这感觉好像以前有过」）；
   - 回想：同一段素材又出现了一次。
   每条线的长度都是两个五维向量之间的直线距离 —— 感觉越像，线越短。
3. **从「此刻」出发，永远先去「目前能走到的最近的那一个」。** 走到一个点，就把它的邻居都标上「从这儿过去要多远」；然后在所有标过的点里挑最近的一个走过去……如此重复。每走到一个点 = 画面上弹出一个节点（= 想起一段记忆）。所以**弹出的顺序就是「和此刻的感觉由近到远」的顺序**，不是我们排的。

真实的数（`build_memory()` 算的，2026-10-23）：最先被想起的三段是 `17 面部瓦解`（距离 1.14）、`原片 1:01`（1.43）、`原片 1:36`（1.53）。找到 John 的那条路：
```
此刻 ─1.53─ 原片 1:36 ─2.61─ 11b 卡拉比丘 ─0.47─ 15 开头 ─0.95─ John（02 走廊背影）
                                                       总距离 5.57，第 28/36 个被想起
```
（最长的一跳 2.61 在中间：从「现实的原片」跳进「高维的卡拉比丘」，然后很快经过「开头」到了 John —— 这条路本身就像故事。）

**为什么用它，不用别的：**
| 算法 | 像什么 | 为什么不用 |
|---|---|---|
| 广度优先（BFS） | 一圈一圈往外数「隔了几步」 | 不管感觉差多远，只数步数 —— 一段完全不像的记忆只要隔一步也会先被想起，不像回忆 |
| A*（带方向的搜索） | 知道目标在哪，朝着它找 | 她**不知道**自己在找 John；A* 会让搜索一开始就朝 John 偏，故事就假了 |
| ⭐Dijkstra | 墨水洇开：近的先到，远的后到，不预知目标 | 正好是「在记忆里漫无目的地找，直到认出它」 |

**这条搜索说出来的故事（都是算出来的，不是写的）：**
- John 在第 **28/36** 个才被找到，路径走了 4 跳，总距离 5.57 —— 按音乐的感觉，John 是离「此刻」最远的记忆之一。
- `CONFIDENCE 0.31` = (1 + 两个五维向量夹角的余弦) / 2：此刻和 John 的「感觉方向」几乎相反。
- → 她抓住的，是和此刻最不像的东西（👤2026-10-23：这个故事定了）。
- 「心魔」（v4）= 前 11 个被想起的记忆里和 John 最不像的那段（余弦 −0.90）；框里转的是那段记忆**自己的声音**画出的形状（延迟嵌入：把同一条声波和它晚一点点的自己、再晚一点点的自己当成 x、y、z 三个坐标，一条声音就变成空间里一团在转的线 —— 声音有规律，形状就有规律）。

**⚠️哪些是数据，哪些是我们的选择（如实写）：**
| 是数据（不能改，改了就不说真话） | 是选择（可以改，改了故事会变） |
|---|---|
| 每段记忆的五个感觉数 | 用哪五个通道当「感觉」 |
| 线的长度、弹出顺序、第 28 个、0.31 | 连哪几种线、情绪近邻取几个（k = 3） |
| 心魔框里的形状 | 心魔怎么挑（「前 11 个里最不像 John 的」） |
| 每次弹出都踩在真实的起音 / 拍点上 | 弹出**什么时候**发生（v4 为了三段结构和最后四声重新分配了时间；顺序和数值不变） |
| 点的大致位置（PCA 前两维） | 位置被轻轻推开防重叠（推开量写在 .json 里）；目标是 John 本身（故事定的） |

**为什么这件事有意思**：搜索本身就是一种「回忆的模型」—— 近的先想起、远的后想起、想起的过程沿着记忆之间真实存在的联系走。我们没有给她写「想到 John」这句台词，是图和距离让她在第 28 个才想到 —— 这比任何写出来的情节都更像回忆。数学在这里是积木（距离、搜索）和审计（每个数都能对回去），故事和情绪（她在找什么、找到时意味着什么）仍然由 Thymos 定。

## B 版：成分树 —— 她的脸被读成数据（独立版）
源：网页端生成的全息女性视频（裁肩 v2），配乐 45.12 s 起。

| 画面上的东西 | 它是什么 |
|---|---|
| 三层节点 | 同一帧在三个亮度阈值（0.45 / 0.65 / 0.85）下的连通域：低阈值 = 大块（头发、脸的亮面），高阈值 = 最亮的小点（高光） |
| 短实线 | **成分树**：高阈值的每一块一定完整地落在低一层的某一块里面，这条线连它和它的「父」（自检逐像素验过） |
| 虚弧 + 箭头 | 中间层所有质心的**最小生成树**（把所有点连起来、总长度最短的那棵树），从面积最大的那块出发 |
| 灰底白形的框 | 低阈值连通域的外接框 + 它真实的形状（遮罩）；太大的块只画四个角，不盖住脸 |
| `x: 835  y: 389` | 质心的真实像素坐标（源视频 1280×720 的坐标） |
| 细折线 | 追踪：同一个亮斑最近 1 秒走过的路（逐帧最近邻关联） |
| 红框放大镜 | 强起音（威胁峰 ≥ 0.55）那一刻，最亮的那块高光被放大 ×4（取起音那一帧的像素），写上它的编号、坐标、面积、平均亮度、起音强度和时间 |

## 自检
`python -m unittest tests.test_info_graph`（12 项）：连通域 == 暴力 BFS；面积 / 质心 / 外接框；MST 总长 == Kruskal；Dijkstra == Bellman-Ford；贝塞尔端点与中点；追踪 ID 保持；成分树父子逐像素包含；节点特征 == 感官通道平均（直接重算）；路径边权和 == John 的最短距离；CONFIDENCE == 公式；PCA 坐标 == 投影；每个弹出时刻都是真实起音。
