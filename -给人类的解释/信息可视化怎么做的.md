# 信息可视化怎么做的（`tools/info_graph.py`）

> 参考：`Projekt_Visual/_参考库/信息可视化_节点坐标.gif`、`AI Strategy.mp4`（+ MACHINE BEHAVIOR 的版式）。拆解：`_参考库/分析_信息可视化/分析.md`。
> 👤：「这个效果很有用，因为信息量巨大！I just love graphic with info, not just fancy decorations」
> ⭐判据：**符号说真话** —— 画面上每个点、每条线、每个数字都能对回一份真实数据；没有一个是为了好看编的。

## 一句话
参考片的「语法」是：**点 = 被检测到的东西，框 = 它真实的包围盒，线 = 它们之间的某种关系，小字 = 它的真实坐标**；画面靠「只有 3 种图元、字又小又暗、黑底占大半」不乱，靠「冲击时信息最多、安静时只剩一个点」有节奏。我们把这套语法套到两种真数据上。

## A 版：记忆图谱 —— 06「一个名字」（1:55.51–2:08.31）
**故事**：狂语之后，她在自己的记忆里找一样东西。找遍了，最后找到的是 John。

| 画面上的东西 | 它是什么（真数据） |
|---|---|
| 每个小方框 / 缩略图 | 剪辑表 `剪辑表_v4_0-97.txt` 里的一个镜头（= 到 06 为止她「经历过」的画面），缩略图 = 那个镜头中间那一帧的真实画面 |
| 节点的位置 | 这个镜头那段时间里，感官五个通道的平均值（心跳 β、威胁 θ、饥饿 η、张力 τ、每秒起音数 ρ），标准化后做 **PCA**（主成分分析）投到两维。坐标轴上写着两根轴分别由哪几个通道组成（载荷）和各占多少方差 —— 位置本身就是信息：离得近 = 那两段音乐「感觉」像 |
| 带十字的方框「此刻」 | 06 段自己的五个数（她现在的感觉），投进同一个坐标系 |
| 细实线 | 故事线：剪辑顺序上相邻的两个镜头 |
| 虚弧 | 情绪近邻：五维感觉空间里最像的 3 个（kNN） |
| 点线 | 回想：同一段素材在剪辑表里再次出现，连回上一次 |
| 黄（酸性版）/ 白（黑白红版）的虚弧 + 箭头 | **搜索**：从「此刻」出发的 Dijkstra 最短路（边的长度 = 两段感觉的差距），箭头 = 从哪找到了哪 |
| 什么时候弹出下一个节点 | 06 段里每一个真实起音（威胁峰 ≥ 0.3）弹出一个 → 拍点打在「被想起的那一段记忆」上，不是整个画面跳 |
| 红线 + 大框 | 找到 John（02 走廊背影）后，路径变红；之后的强起音沿路径跑一颗红点 |
| `MATCH: JOHN-117  CONFIDENCE 0.31` | 真算的：(1 + 此刻和 John 两个五维向量的夹角余弦) / 2。⚠️是 0.31 不是物件.md 草拟的 0.62 —— 也就是说按音乐的感觉，John 是她记忆里离「此刻」**最远**的那一段之一（搜索几乎走完整张图才到）。这本身是个故事：她抓住的是和此刻最不像的东西 |
| 右上的条形 | 此刻 vs 最新找到的那段（找到后 = John）的五个标准化数值，和余弦 |
| 底部时间轴 | 0:00 → 2:08 的四条感官曲线、每个起音（高度 = 强度）、乐句格、情绪大图的段名、每个镜头的区间；最新被想起的那段有一根引线连到它在时间轴上的位置 |

镜头：开场已经在高速平移（从「最早的记忆」那一侧扫向「此刻」，先快后慢）；之后每弹出一个节点，相机用临界阻尼弹簧追过去（= 一次「进」一次「缓」）；找到 John 后 2.5 s 拉远到能看见整条路径。整段不停。

## B 版：成分树 —— 她的脸被读成数据（独立版）
源：网页端生成的全息女性视频（裁肩 v2），配乐 45.12 s 起。

| 画面上的东西 | 它是什么 |
|---|---|
| 三层节点 | 同一帧在三个亮度阈值（0.45 / 0.65 / 0.85）下的连通域：低阈值 = 大块（头发、脸的亮面），高阈值 = 最亮的小点（高光） |
| 短实线 | **成分树**：高阈值的每一块一定完整地落在低一层的某一块里面，这条线连它和它的「父」（自检逐像素验过） |
| 虚弧 + 箭头 | 中间层所有质心的**最小生成树**（把所有点连起来、总长度最短的那棵树），从面积最大的那块出发 |
| 灰底白形的框 | 低阈值连通域的外接框 + 它真实的形状（遮罩）；太大的块只画四个角，不盖住脸 |
| `x: 835  y: 389` | 质心的真实像素坐标（源视频 1280×720 的坐标） |
| 细折线 | 追踪：同一个亮斑最近 1 秒走过的路（逐帧最近邻关联） |
| 红框放大镜 | 强起音（威胁峰 ≥ 0.55）那一刻，最亮的那块高光被放大 ×4（取起音那一帧的像素），写上它的编号、坐标、面积、平均亮度、起音强度和时间 |

## 自检
`python -m unittest tests.test_info_graph`（12 项）：连通域 == 暴力 BFS；面积 / 质心 / 外接框；MST 总长 == Kruskal；Dijkstra == Bellman-Ford；贝塞尔端点与中点；追踪 ID 保持；成分树父子逐像素包含；节点特征 == 感官通道平均（直接重算）；路径边权和 == John 的最短距离；CONFIDENCE == 公式；PCA 坐标 == 投影；每个弹出时刻都是真实起音。

## 想要 X 就调 Y
| 想要 | 调 |
|---|---|
| 搜索更快 / 更慢找到 John | `memory --thr`（起音阈值；越低弹得越多） |
| 情绪近邻更多 / 更少 | `memory --k` |
| 换段落 | `memory --seg0 --seg1`（节点仍是剪辑表 0–97 的镜头） |
| B 的点更多 / 更少 | `track --levels`（阈值）、`--min-area` |
| B 换源 | `track --src 视频 --start 歌里的秒数`（`--crop-bottom` 去掉源自带的 HUD） |
| 配色 | `--palette bwr`（黑白红）/ `acid`（酸性点缀：黄绿给搜索前沿，红仍只给 John / 路径 / 放大镜） |

## 每一版改了什么（看接触表自评）
| 版本 | 改了什么 | 为什么 |
|---|---|---|
| A v1 | 首版：PCA 坐标 + 三种边 + Dijkstra 按起音弹出；镜头弹簧跟住最新节点 | —— |
| A v2 | 找到的 John 大框常驻（全段唯一的大框）；右上加「此刻 vs 最新节点」的 z 向量条形 + cos，找到后列出整条路径的 d；开场离图更近、初速更快 | v1 里 John 找到后框又缩回去，高潮没有形；中段只有「一堆小框」，缺一个能读的对照 |
| A v3 | 「注意力」分层：搜索前沿 + 它的图邻居 + 此刻（找到后 + 整条路径）的标签全亮、大一号（13 / 12），前沿再加特征和坐标；已访问的只剩一行「时间 + 坐标」；未访问的只剩 `#编号`。1080p 实测字号（Consolas 8–9 px 读不清、暗色要 ≥ 12）→ 全部字至少 11、暗字至少 12，读不清的字段不画。开场第一帧故事线已经长到三分之一、「此刻」的近邻边已在往外长。HUD 加 `FOUND AT POP 28/36` | 主会话看 v2：中段满屏同一字号同一亮度的小字成了纹理；开场第一帧偏空 |
| A v4 ⭐ | 👤定的三段结构（对齐乐句 115.56 / 121.96 / 128.36）：①搜索；1:58.55（起音）弹出「心魔」= 前 11 个里和 John 最不像的那段记忆（#32 静帧 19b 卡拉比丘局部，cos(z, z_john) = −0.90），框里是那段记忆**自己的声音**（原曲 1:33.12–1:34.72，带通 30–250 Hz）的延迟嵌入 (x(t), x(t−τ), x(t−2τ))，τ = 主频周期的 1/4，在转、在走；它抖（幅度 4 + 18·当前威胁）、在起音上闪，1.15 s 后被压下（缩成点、变暗），标 SUPPRESSED，搜索继续。②2:01.96 硬切到第二个画面：放大到前沿附近，线和节点自己抖，幅度 A = ramp·(2 + 9·张力 + 16·威胁) 像素，相位沿图传播（离最新节点每多一跳晚 1.4 rad）；起音那 2 帧焦点标签反白；弹出加快（第二段 4.6 s 里 12 个）；右下换成 A(t) 的示波。③四声 2:06.554 / 2:06.943 / 2:07.342 / 2:07.741：路径逐跳点亮，第四声 = 弹出 John（第 28/36 个）= 锁定，所有抖动同时停住；然后冲进 John 的框（变焦按指数），框里交叉淡入粒子海 v4 的首帧，最后 3 帧 = 粒子海 v4 第 0 帧（硬接）。**顺序和所有数值和 v3 一样**，只改弹出的时间分配：事件池 = 起音（威胁峰 ≥ 0.3）∪ 拍点；Dijkstra 找到 John 就停（后面 8 个节点不弹） | 👤：「质感来自于有审美的信息量」；要一个被压下的小心魔、一个躁动的第二画面、踩在最后四声上的 find it、作为粒子海的入口 |
| B v1 | 遮罩框盖在原位（像 AI Strategy） | 灰底遮罩把鼻子、嘴、脸颊盖成一块块「打码」，脸没了 |
