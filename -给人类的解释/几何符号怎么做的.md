# 几何符号怎么做的（`tools/geo_symbols.py`）

> 2026-10-22，用户睡觉时由子代理做的「几何动态 / symbols」这条线。
> 拆了两个参考：`Projekt_Visual/_参考库/分析_Modular/分析.md`（一镜到底的模块拼装）和 `分析_FITC2015_Titles/分析.md`（FITC 东京 2015 片头 + 它的黑白 animatic）。
> **只学语法（网格、缓动、节奏、转场逻辑、排版层级），图形全是自己画的**：字体是我们自己在 3×5 格上设计的，构图、主题都是原创。

## 一句话

画面上的每个数字、每根刻度都是真的；东西不「出现」，而是一笔一笔**画出来**、一层一层**退到远处**；拍点只落在一个具体的东西上（一个字、一个框、一格），整幅画面从不跟着鼓点放大或抖。

## 学来的 5 个手法（每个都是一段很短的数学）

| 手法 | 从哪学的 | 我们的做法 | 数学 |
|---|---|---|---|
| ① 模块字体 + 笔画组装 | FITC：字是由横、竖、弧、点拼出来的，一笔一笔画出来、一根一根掉 | 自己画的 0–9（3×5 格，笔宽 0.62 格）；新数字的笔画错开 1.5 帧依次画出：条从一端长，弧**边转边长**；旧数字退到第 2–4 层时笔画一根根消失（不淡出） | 每笔一个开始时刻，进度走 ② 的缓动 |
| ② 先快后慢 | Modular 0:42 那一下实测：前 3 帧每帧剩 72 %，之后每帧剩 89 % | 所有「到位」都用同一条曲线，终点速度不为 0（不会停死） | P(t) = 0.6(1−e^(−t/3 帧)) + 0.4(1−e^(−t/9 帧))，再归一 |
| ③ 对数螺旋拉远 | Modular 结尾的套娃式倒数 | 第 i 个数字放在「世界」里尺度 Rⁱ、方位 i·φ 的地方；镜头每个拍点往外退一层 → 新数字永远在同一个位置出生，旧数字沿一条对数螺旋缩进消失点。螺旋本身用细线画出来（= 镜头真实走过的轨迹） | 屏幕 = 中心 + R^r·旋转(rφ)·v0，r 每拍减 1；自检逐像素核「每个数字出生时位置完全一样」 |
| ④ 相位环 | Modular 的扇形扫出 | 四个同心环的扫角 = 真实相位：拍 / 小节 / 乐句 / 整首歌；乐句环有 16 个刻度，红点 = 此刻 | 扫角 = 2π × 相位 |
| ⑤ 阶梯条 + 标签框 + 字阵 | Modular 的分段条；FITC 的「标签框填实 1 帧」和字阵行选择条 | 24 个频带的真实能量量化成 8 级台阶，回落每 2 帧掉一级；「ONSET」框只在真实起音那一帧填实；字阵里被认出的那一行有选择条扫过 | dB → floor(级数)；起音来自 `感官.json` |

## 做了哪几条片子

### A 版：绑《Can't Kill Us》（`Projekt_Visual/MV_Cant_Kill_Us/样片/几何符号/`）
- **倒数**（`countdown`）：情绪大图第 10 段「憋住」—— 192.36 → 198.76 一共 16 拍，屏幕上的数 = **离冲顶还剩几拍**（16 … 1）。最后半拍所有东西收缩成一个红点，198.76 切进冲顶。⭐当前最好：`21_几何符号_倒数_v5`（cold / `_黑白红` / `_酸性` 三种配色）。
  - 建议时间槽：剪辑表 **3:12.32 – 3:18.76**（比乐句点 192.36 早 1 帧切进来；片子本身从 191.96 开始，前一拍已经在动）。
- **字阵吸收**（`matrix`）：第 07 段「吸收」。右边是狂语段（77.11–115.51 s）里**每一个真实起音**排成的 142 格「声音」，格里的小字形由那个起音的张力选、粗细由威胁定；吸收段里每来一个起音，就按特征最近邻「认出」一格：那格在自己的起音上亮 3 帧 → 收成一个点 → 沿缓动飞进左边她的环；环在落点被撞得往里凹一下再弹回，外面长出一根针（长度 = 那个声音的威胁）。环中间的数字 = 已吸收 / 142（真数）。当前 `21_几何符号_字阵吸收_v3`（+ 黑白红 / 酸性）。建议 2:08.36 – 2:21.14。

### B 版：独立 motion design（`Projekt_Visual/MotionDesign/几何符号/`）
- **筛**（`sieve`）：埃拉托斯特尼筛。13×13 = 1..169，自己定的 120 BPM：每个素数 p ≤ 13 一小节，从 p² 开始按步长 p 把倍数一格格划掉（数字收成一道横线；被第二个素数再划一次就多一道短线 —— 重复劳动也画出来）；左边的大数字是当前的 p，换 p 时沿对数螺旋退场；最后剩下的 39 个素数依次点亮，大数字变成 **39 = π(169)**。声音是筛自己的声化（每划一格一个「嗒」，音高 = 行）。⭐当前最好：`01_几何符号_筛_v4_黑白红` / `_酸性`。

## 配色
- `cold`：本片的冷灰白 + 一个红点（A 版默认）。
- `bwr` 黑白红：纯黑底、纯白；「此刻」那一个东西整个是红的（前位数字 / 正在开口的那一格）。
- `acid` 酸性：紫黑底 + 偏紫的灰；「此刻」是荧光酸橙，选择条 / 标签闪是暗洋红。

## 怎么跑
```
python tools/geo_symbols.py countdown --ver v5 [--palette cold|bwr|acid]
python tools/geo_symbols.py matrix --ver v3 [--palette ...] [--start 128.36 --end 141.14]
python tools/geo_symbols.py sieve --ver v4 [--palette ...]
加 --still 秒数 --out 临时目录 只出一帧看构图；--scale 0.5 出小样。
```
每条输出：`.mp4`（带声音）+ `_接触表.jpg` + `.json`（逐帧真值：显示的数、相位、频谱台阶、配对……）。同名文件存在就停，不覆盖。
自检：`tests/test_geo_symbols.py`（12 项：缓动、螺旋自相似、字体、阶梯回落、倒数 = 剩余拍数、字阵配对不重复、筛的结果 = 39 个素数……）。

## 迭代记录（每版改了什么）
| 片子 | 版本 | 改了什么 / 为什么 |
|---|---|---|
| 倒数 | v1 | 新数字出生时从画外 2 倍大飞进来 → 笔画没画完就在画面里乱飞，像散落的方块 |
| | v2 | 改成在前位原地画出、同一拍里上一个数字从同一个位置退走（替换式转场）；但新旧两个字叠了 3 帧，弧转 90° 拼出奇怪形状 |
| | v3 | 笔画变细（1 → 0.62 格）、新字晚 2 帧开画、弧只转 45°、画出螺旋引导线；问题：最后的「1」没画完就被收走 |
| | v4 | 最后一个数字快画（半拍内画完），收缩推迟到冲顶前 5 帧 |
| | v5 | 细笔画时字形外缘对齐（「5」左上的小凸起没了），「7」改成 S 形两段弧（v1–v4 的 7 接口有缺口）；出三套配色 |
| 字阵吸收 | v0 | 只出过静帧：环太大、字阵太小，像一张表 |
| | v1 | 字阵占右半幅、加飞行轨迹 —— 但整片同一个中灰，像数据面板，没有情绪 |
| | v2 | 字阵暗下去、伸出画外；只有被认出的那格亮；环被撞凹、长出针 —— 但整段几乎不动（帧差 ~0.4） |
| | v3 | 加镜头：慢推 + 乐句边界一次「进」（只改速度）；出三套配色 |
| 筛 | v1 | 两位数（11、13）被推出画面左边；镜头推到 ×1.49，网格顶行被裁；结尾没有收束 |
| | v2 | 结尾加「39 = π(169)」；推近收到 ×1.2；但两位数仍出画 |
| | v3 | 两位数居中 + 宽度封顶；但前位数字盖住了上一层 |
| | v4 | 螺旋中心右移、网格右移 |

## ⚠️没做到 / 没验到
- **我听不到声音**：倒数的拍点、字阵的起音都是按 `感官.json` 对的，「卡得舒不舒服」要用户听。筛的声化也没人听过。
- 字阵吸收仍然偏「信息图」，情绪弱于倒数；142 格同时在画面里，密度偏高。
- 筛 v4 结尾的「39」左缘离画边只有 ~3 % 画宽，网格最右一列被镜头推近裁掉半格。
- 倒数 v1–v4 是用旧的「7」字形渲的；现在重跑 v3/v4 会得到新字形（代码里留了注释）。
