合成器词表15 个词 · 听 + 看 · v2

够用来指挥的 15 个词。每个词一句人话、一段几秒的声音、它在示波器上的样子。 示波器画的是一个立体声 wav：左声道推光点左右走，右声道推光点上下走。真立体声的例子，听到的就是画出来的；延迟嵌入的例子，另有一个「听音色」的版本（只有真实的声音）。所有声音都是 numpy 现算的，没有采样，A 小调，120 BPM。

左 = x，右 = y
两个声道一样 → 一条 45° 斜线；只有左 → 横线；只有右 → 竖线；左右各走各的 → 一团。
延迟嵌入
单声道的声音，把右声道设成左声道晚 τ（四分之一个周期，几毫秒）。正弦 → 圆；任何稳定的音 → 一个闭环；乱的声音 → 乱结构。⚠️这个副本只为画图：外放时第 2、6、10… 次泛音会被抵消，所以听音色用每格的「听音色」播放器。
亮 = 慢
光束走得慢的地方亮，快跳的地方暗。所以方波只剩四个亮点，失真的方块四个角最亮。每个例子的放大倍数单独调过（= 示波器的 V/div 旋钮）。

任何声音 = 基音 + 一串整数倍的泛音。泛音的多少和配比就是「音色」：为什么钢琴和小号弹同一个音听得出不同。

一个音的音量怎么随时间走：Attack 起多快 / Decay 落多快 / Sustain 按住时停在多高 / Release 松开后多久消失。

视频里的声音是给示波器用的：右声道是左声道晚几毫秒的副本，外放会抵消一部分泛音。听音色请点上面这个。

05

滤波器（截止 / 共振）Filter (Cutoff / Resonance)

把一部分频率削掉。低通 = 只放低频过去；截止频率 = 从哪开始削；共振 = 在截止那里鼓起一个尖峰，会「啸」。

听音色

视频里的声音是给示波器用的：右声道是左声道晚几毫秒的副本，外放会抵消一部分泛音。听音色请点上面这个。

延迟嵌入 τ = 4.54 ms（55 Hz） · 放大 ×1.949 · 6.0 s · 示波器用 wav · 听的 wav

听锯齿低音被「捂住 → 打开 → 再捂住」（24 dB/倍频程低通）；后半共振拉高，开合时有一声哨音在扫。

看截止低：近乎一个光滑的环；打开：边缘出现锯齿和尖刺；共振高：环上缠了一圈高频的小波纹。频谱图里橙线（截止）以上的泛音变暗，共振时橙线附近亮一条。

07

调制Modulation

让一个信号去推另一个参数。LFO、包络、键盘力度都可以是「源」；音高、截止、声像都可以是「目标」。连线 = 调制矩阵。

听音色

视频里的声音是给示波器用的：右声道是左声道晚几毫秒的副本，外放会抵消一部分泛音。听音色请点上面这个。

延迟嵌入 τ = 4.54 ms（55 Hz） · 放大 ×2.338 · 4.2 s · 示波器用 wav · 听的 wav

听同一段贝斯弹两遍：第一遍截止固定（闷）；第二遍每个音的包络去推截止（每下都「哇」地张嘴）。

看第一遍形状一直很圆；第二遍每个音刚起来时满是尖刺，然后迅速收成圆。

08

用一个振荡器去快速推另一个振荡器的相位。两个音的频率比定「哪些泛音」，推的深度定「多亮」。整数比 → 乐音；非整数比 → 钟、金属。

听前半：一个音被慢慢「拧亮」，从长笛变成铜管；后半：三下钟声（比例 3.5）。

看圆被拧成越来越多瓣的花（深度越大瓣越多）；钟声是不闭合、一直在转的花纹。

09

两个振荡器的音高故意差一点点。差出来的那一点会变成「拍」：一种慢慢起伏的摇摆感。

10

齐奏Unison (Supersaw)

同一个音用好几个略微失谐的振荡器同时弹，再左右铺开。trance、EDM 那种又宽又厚的「墙」就是它。

这一格是真立体声：视频里的声音就是要听的声音。

真立体声（齐奏声部左右铺开） · 放大 ×2.272 · 6.0 s · 示波器用 wav · 听的 wav

11

失真 / 饱和Distortion / Saturation

把声音推得太猛，波形的顶被压平。轻的叫饱和（温暖、变肥），重的叫失真（毛、凶）。

视频里的声音是给示波器用的：右声道是左声道晚几毫秒的副本，外放会抵消一部分泛音。听音色请点上面这个。

延迟嵌入 τ = 4.54 ms（55 Hz） · 放大 ×5.127 · 6.0 s · 示波器用 wav · 听的 wav

听一个圆润的低音，越推越粗、越凶，最后像吉他音箱。

看圆慢慢被压成圆角方块：顶被削平的地方，光束停留得久，所以四个角最亮。

12

延迟 / 混响Delay / Reverb

延迟 = 回声，一下一下清楚地重复；混响 = 成千上万次回声糊在一起，变成「空间」。反馈 g 决定回声多久消失：g < 1 会散，g → 1 永远不停（这就是 IIR 的极点）。

听音色

这一格是真立体声：视频里的声音就是要听的声音。

真立体声（乒乓：回声一左一右；混响：左右不一样的衰减） · 放大 ×1.976 · 7.0 s · 示波器用 wav · 听的 wav

听前半：一下拨弦，回声左右左右地弹走、越来越暗；后半：三个音进了一个大厅。

看干声在中间是斜线；回声只在一边时变成横线 / 竖线；混响让左右各走各的，变成一团云。

13

侧链Sidechain

让 A 的音量被 B 控制：kick 一打，铺底就被压下去再弹回来。舞曲的「抽吸感」就是它。

听音色

这一格是真立体声：视频里的声音就是要听的声音。

真立体声：pad = 左右两个微失谐的正弦（慢转的椭圆），kick 居中（斜线） · 放大 ×2.333 · 4.6 s · 示波器用 wav · 听的 wav

听第一小节：kick 和一个持续的长音叠在一起；第二小节：每打一下 kick，长音就让开再回来，整体在呼吸。

15

音序器Step Sequencer

一排格子（常见 16 步）循环播放：每一格放不放音、放哪个音。很多电子乐就是几排格子叠出来的。

听音色

视频里的声音是给示波器用的：右声道是左声道晚几毫秒的副本，外放会抵消一部分泛音。听音色请点上面这个。

延迟嵌入 τ = 1.52 ms（按 E3 165 Hz） · 放大 ×2.792 · 8.5 s · 示波器用 wav · 听的 wav

听16 格的旋律循环两遍：每一格一个音（A 小调五声），有的格换一种波形，空格就停一下。

看一步一个干净的闭环：音高变 → 环的倾斜和圈数变；波形变 → 圆 / 菱形 / 方 / 锯齿换着来；空格 = 只剩余辉。

和我们的理念接上的三处（_设计/理念_示波器与处理器.md）

· 延迟的反馈 g 就是 IIR 的极点：g < 1 回声会散，g → 1 永远不停，g > 1 炸开。和「FIR / IIR 生长」是同一个数学。
· 琶音器那一格：两个音的频率比 = 音程 = 李萨如图的瓣数。越协和的音程图越简单（八度 1:2 是 ∞，五度 2:3 是三瓣）；平均律不是整数比，所以图形在慢慢转。
· 调制那一格就是调制矩阵的一条线：源（包络）× 目标（截止频率）× 强度。作曲器里每条线都会写进事件轨，画面直接读。
