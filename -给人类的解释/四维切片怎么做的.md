# 四维切片怎么做的（`tools/four_d.py`）

> 「全息 AI 坠入高维」：一个四维的东西穿过我们的三维空间，我们只看得见它和「此刻这一层」的交集。
> 这份是给人看的原理。参数、命令行见文件开头的说明；效果库那一行是索引。

## 一句话

在四维里摆一个形状，拿一块「三维的切片」（超平面 w = c）去切它，把切出来的三维截面用光线去照、渲染成图。
切片动（c 变）或者形状在四维里转（xw、zw 平面里转），截面就会变形、裂开、长洞 —— 但它其实一直是同一个东西。

## 四个零件

| 零件 | 做什么 | 为什么 |
|---|---|---|
| 四维距离场 f(x,y,z,w) | 每个四维点到形状表面有多远（里面是负的） | 一个函数就能描述任意形状；切片 = 把 w 固定成 c，直接得到三维距离场 |
| 球追踪 | 从相机每个像素射一条光线，每步走「离表面最近的距离」那么远，碰到就停 | 不需要做网格，四维的东西切出来直接渲 |
| 红 = 相切 | 四维表面的法向几乎垂直于切片（法向的 xyz 分量 → 0）的地方涂红 | 数学上（Morse 理论）截面的形状只会在这种点「变拓扑」：出生、裂开、长洞、消失 |
| Betti 数 | 在粗体素网格上真的数：几块（b0）、几个洞（b1）、几个空腔（b2） | HUD 上的数字是数出来的，不是写死的 |

她的模型（Tripo 出的 glb）→ 先算成 256³ 的三维距离场（每个格子到网格表面的距离，符号用缠绕数判里外）→ 再用 extrude / spin / twist 这些算子推广到四维。

## 雕塑光（`--look sculpt`，Golden Age）

一盏硬主光，固定在世界里（相机转的时候光不动，明暗交界线在形体上慢慢滑）+ 软阴影 + 凹处变暗（AO）+ 一点高光，几乎没有补光 → 黑是真黑。
被超平面切出来的平切面不受光（正对相机就是一块死黑），所以让它自己发光、加一层细横线，读得出「这是剖面」。
全片只留一个红点（最强的相切处，跨帧跟着走）。

## ⭐浮现：她从手开始长进我们的空间（`--emerge`，👤2026-10-22）

👤 的想法：用四维切片表现她**从另一个维度浮现** —— 从手（指尖）开始，慢慢长成完整的人；感觉是**孤独**：空无一物的黑里，慢慢出现一个人。

### 这个四维物体是什么

取她站立的模型（`3D/她.glb`）。在她的身体**里面**，从右手指尖开始算「沿着身体走过去要走多远」—— 这叫**测地距离** D：
指尖 0，手腕大概 0.2，肩膀 0.8，头顶、脚尖最远。

四维物体 = 「身体 × 一个以指尖为顶点的锥」：

  点 (p, w) 在里面 ⇔ p 在身体里，并且 D(p) ≤ w

用超平面 w = c 去切，切出来的就是「身体里离指尖不超过 c 的部分」。c 往上扫 → 她从指尖长出来：手指 → 手掌 → 手腕 → 小臂 → 肩 → 躯干 → 头和另一只手、两条腿。
生长前沿就是一块四维截面的切口（自发光 + 细横线），皮肤上紧挨着前沿还有一圈亮带。

### 为什么用「沿身体走的距离」，不用直线距离

她垂着的手离大腿只有几厘米。用直线距离，手一长出来大腿就跟着亮了 —— 像隔空跳过去。
沿身体走（只在体内传播），要从手 → 胳膊 → 肩 → 躯干 → 胯 → 才到大腿。**动作沿结构传播**（我们的规矩）。
实现：在 256³ 的格子里，只在身体里面，一格一格往外推（每格往 26 个邻居推，直走加 1 格、斜走加 √2 / √3 格），推到不再变为止。显卡上几秒。

### 红点 = 她第一次碰到我们的空间

锥尖（指尖那一点）抹圆了一点点，所以超平面第一次碰到这个四维物体时是**真正的相切** —— 那一刻、那一点是红的。之后切口上法向的 xyz 分量大多是 1/√2，不红；红点慢慢熄掉。
⚠️诚实：之后还有别的相切 —— 前沿绕过胸口自己合上的地方（两路测地线在那里相遇，D 的梯度 → 0）、头顶长完那一下，探测器都抓得到（v3 里胸口亮过一个红点）。它们是真的，但画出来像装饰，所以成片只留出生那一下（见下）。

### 渲染上的一个坑：「沿身体走的距离」不能直接拿来跨步

球追踪每步要走「离截面最近的距离」，这要求距离函数每走 1 个单位最多变 1 —— 但测地距离在手和大腿之间的缝里**跳**（缝两边一个是 0.1、一个是 2.0）。
解决：另算一个「它的下包络」D_L（从体内的值出发在整个空间里往外推，保证每走 1 最多变 1），**用 D_L 决定走多远、用真的 D 判断碰没碰到**。阴影和 AO 也用 D_L。自检里用暴力最近距离验证了它确实是下界。
⚠️第一版踩的坑：体外的 D 也用了这个下包络 —— 结果手的小值隔着空气灌到大腿表面，皮肤（体内体外两个格子之间插值）比体内先长，大腿上冒出一片蕾丝状的白斑（实测大腿表面 0.7、体内 1.33）。
现在体外的 D 改成「取最近的体内值」一层层往外抄（法向延拓），下包络只拿来跨步。

### 镜头

- 生长节奏：「进度」= 0.7 × 前沿走了多远 + 0.3 × 已长出的体积，进度按「一开始慢、指数加速」走。
  只按前沿距离匀速走（v1）的话，躯干一秒内就灌满了 —— 画面在那一秒猛地一鼓；掺进体积后，躯干这种粗的地方前沿自己放慢。第 ~4.6 秒全身长完，剩下 ~1 秒她完整地、孤零零地在那儿。
- 相机：贴着指尖开始，**按对数匀速往后退**（每秒距离乘同一个倍数 —— 画面里是恒定的「退开」感，不从静止开始、不停）；对准点 = 已经长出来的部分的重心（略平滑），镜头跟着生长从手走到身体中心。最后她在一大片黑里只占画面的一小块。
- 前沿：皮肤上紧挨着前沿的一条细亮带（1.5 cm 级）+ 切口自发光 —— 远景里也读得出「正在长」。
- 红点只留出生那一下（r < 0.08）。前沿在胸口绕一圈自己合上、头顶长完时也有真相切，但红点落在胸口像个装饰，所以不画。

### 自检（`tests/test_four_d_grow.py`，合成的 U 形，不读模型）

- U 形两根柱子中间有缝：右柱顶的测地距离 ≈ 下去 + 横过去 + 上来的路长（误差 < 10 %），远大于穿缝直线距离 → 不跨缝。
- 沿柱子直走：测地距离 = 直线距离。
- w = w0（c = 0）时只有指尖那一格；c 稍大时只在指尖附近。
- 体积随 c 只增不减；c ≥ D_max 时截面 = 整个身体，逐体素相等。
- 下包络 D_L 每格最多变 1 格长、处处 ≤ D；距离下界 ≤ 暴力算的真实距离。
- 锥尖处相切（法向 xyz 分量 < 0.32），前沿中段 = 1/√2。
- 光线追踪：长出来的地方看得见，没长出来的看不见；命中点的真截面 ≈ 0。
