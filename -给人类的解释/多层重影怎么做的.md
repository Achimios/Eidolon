# 多层重影怎么做的（`tools/layer_ghost.py`）

> 参考图：`Projekt_Visual/_参考库/瓦解4.jpg`。
> 👤 2026-10-22 的读法：**就是「带纹理的蒙版和散射的多层叠加」**。
> 它取代了 `lens_ghost.py`（透镜重影）—— 那个把画面扭成了波浪帘子（👤：「太离谱了…甚至给我用上扭曲了」）。
> 这里**没有任何扭曲 / 折射 / 位移场**：每一步都只是「挪一下、乘一下、模糊一下、加起来」。

## 一句话

把她复印几份，每份往下错开一点、染一点不同的颜色；每份都隔着同一块「带颗粒的玻璃」；每份再加一层往竖向漫开的光；全部叠在黑底上。

## 五步

| 步 | 做什么 | 为什么这样 |
|---|---|---|
| ① 多层 | 原图复制 N 份（默认 5），第 k 份整体往下挪 `k × 层距` 个像素（整数，不插值）。越往后越淡，所有份的权重加起来 = 1 | 离散的重影，不是运动模糊；权重和为 1 → 画面不会变亮或变暗 |
| ② 色散 | 每份一个色调；红通道再往上多挪一点、蓝往下多挪一点（越后面的份挪得越多） | 色调按通道归一：几份重合的地方还是白的，只有错开的边上出颜色 —— 像棱镜 |
| ③ 纹理蒙版 | 每份乘一张颗粒蒙版，平均值正好 = 1 | 颗粒**从参考图自己身上抠**（亮度的高频部分，按局部对比度归一，只取有纹理的块，随机拼贴 + 翻转）—— 真实的东西比程序噪声好看（低熵注入） |
| ④ 散射 | 每份 = 一半清晰 + 一半竖向模糊（横向只模糊竖向的 12 %） | 散射只是把光挪到别处，不凭空加光；参考图里的光几乎全是竖着漫的 |
| ⑤ 溢光 + 调子 | 很亮的地方再往外晕一圈；压一点黑位；一条柔和的高光肩 | 高光「开花」；黑底保持黑 |

## 一个量出来的事实（交叉校验）

把参考图的颗粒拿出来算「自己和往下挪 n 像素的自己有多像」（自相关）：

- 往下挪 9 像素：0.77 像；18：0.69；27：0.52；36：0.39
- 往横挪 2 像素以上：几乎不像（≈ 0）
- 红和蓝的颗粒不挪就 0.93 像

意思是：**参考图本身就是同一张带颗粒的图，往下每隔约 9.2 像素叠了 6–8 层**，颗粒跟着层一起走，红蓝颗粒没错开。
所以默认层距 = 9，默认「一张纹理贴在原图上、跟着每层一起挪」（`tex_mode carry`）。
（之前做透镜重影的那位也量出了 9.2 px —— 但它和我用的是同一张图，不算独立验证。）

## 尺寸单位

所有尺寸以「参考图像素」写，乘一个单位 `u` 变成输出像素。
任务单原本说按画宽缩放（1280 / 736 = 1.74），但我们这段素材里她的头宽 ≈ 500 px，参考图里 ≈ 470 px —— 按头宽对齐 `u ≈ 1`。
按画宽放大后颗粒和光晕相对她的脸都粗了 1.7 倍，不像参考图（`25d` 第 4 列就是这个），所以**默认 `u = 1`**；`--unit 0` 可换回按画宽。

## 跟着音乐走

| 感官 | 管什么 |
|---|---|
| 威胁 | 层距 和 能看见几层 |
| 张力 | 红 / 蓝错开多少 |
| 饥饿 | 散射多长 |

时间上：**平时只开四分之一强度**（一点颗粒 + 很浅的重影），只有**强起音**才猛地打开 2 帧、再在约 0.1 秒内退回去。
强起音 = 起音时威胁 ≥ 0.6，而且离上一次打开至少 0.45 秒 —— 这首歌 150 BPM，连着的起音间隔 0.4 秒，于是自然变成「隔一个开一次」。
每 4 帧换一次颗粒排布（打开时也换），颗粒才会闪。

## 想要 X 就调 Y（👤 2026-10-22：「重影NB」→ 再多一点色散、更细腻）

所有旋钮都是 `Params` 的字段：函数里直接传，命令行用 `--set "名字=值,名字=值"`（静帧扫参在 `SWEEP` 表里，选中的组合在 `BEST`；`clip --best` 直接用它）。
倍率类旋钮在「跟着音乐走」那张表之后再乘，所以音乐驱动照样有效。

| 想要 | 调 | 方向 / 说明 |
|---|---|---|
| 彩边更宽（更多色散） | `sep_mul` | 1 → 1.5 → 2：红往上、蓝往下错得更多 |
| 三色彩边（红 / 绿 / 蓝分开） | `chan_g` | 0 = 绿不动；0.5 = 绿往下挪蓝的一半 |
| 颗粒更细 | `tex_scale` | 1 → 0.7 → 0.5（纹粒尺寸倍数） |
| 颗粒更淡 / 更浓 | `grain_mul` | < 1 淡，> 1 浓 |
| 白的地方更平滑（像参考图） | `hl_smooth` | 0 → 0.6：越亮的地方颗粒越弱（平均亮度不变） |
| 重影更密 / 更疏 | `spacing`（静帧）或 `spacing_mul`（视频，乘在音乐驱动的层距上） | 9 → 7 更密 |
| 重影拖得更长 | `n_layers`（+ `n_vis`）、`falloff` | 层数多、falloff 大（衰减慢）→ 更长 |
| 散射更长 | `scatter_r`（静帧；视频里由饥饿决定） | σy，参考像素 |
| 散射更竖 / 更圆 | `aniso` | 0.12 很竖，1 = 圆 |
| 高光更晕 | `bloom`、`bloom_thr` | bloom 大、阈值低 → 更晕 |
| 颗粒固定在画面上，而不是跟着层走 | `tex_mode=screen` | 默认 carry |
| 平时更安静 / 更躁 | `--base`（视频） | 脉冲之间的底强度，默认 0.25 |
| 脉冲更多 / 更少 | `--thr`、`--min-gap`（视频） | 阈值低、间隔短 → 更多 |

**这一轮扫参**（`25e_多层重影_参数扫_v1.jpg`，每格是同一帧的 1:1 裁切）：A 基线 / B 色散 ×1.5 + 绿 0.5 / C 色散 ×2 + 绿 0.5 / D 颗粒 0.7 倍 + 白处平滑 0.6 + 颗粒强度 0.85 / E 同 D 但颗粒 0.5 倍 / F 层距 7、7 层、falloff 0.75。
**选中的组合**（`BEST`）：色散 ×2 + 绿 0.5、颗粒 0.7 倍、白处平滑 0.6、颗粒强度 0.85、层距 7、7 层、falloff 0.75 → 静帧 `25b_多层重影_冷_v3.jpg`、视频 `样片/21_多层重影_全息女性_v2.mp4`。
0.5 倍的颗粒在整帧里已经细到快看不出来，所以选了 0.7 倍。

## 还不像的地方（放大对比里看得到）

- 参考图白的地方底子更平、颗粒只在中间调最亮；我们的颗粒全画面都一样强，还带一点「人字」纹。
- 参考图的大块橙色 / 青色是它原图自己的灯光；我们的原图是单色蓝 → 「参考色」版只有细彩边，没有大色块。
- 画面最上面几行：往下挪的层在顶上没有东西可挪，用最顶一行补（不然每层会在顶上留一条亮线）。

## 怎么跑

```
python tools/layer_ghost.py sheet [--t 4.0]
python tools/layer_ghost.py clip [--palette cold|ref] [--thr 0.6 --min-gap 0.45 --base 0.25] [--no-hud] [--best] [--set "sep_mul=2,..."]
python tools/layer_ghost.py sweep [--t 4.0 --crop-x 520]
```
自检：`python -m unittest tests.test_layer_ghost`
