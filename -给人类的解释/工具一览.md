# 工具一览（tools/ 和 src/ 里每个文件是干什么的）

> 2026-10-20。都在 4_Eidolon 根目录跑：`.venv/Scripts/python.exe tools/xxx.py`（本仓库的虚拟环境，装了 torch 等）。
> 默认输入 / 输出都是《Can't Kill Us》的作品文件夹 `Projekt_Visual/MV_Cant_Kill_Us/`（下面简称「作品/」）。
> 软件和作品分开：代码在这里，生成出来的东西都落在作品文件夹。

## src/ —— 被别的脚本调用的库

| 文件 | 干什么 | 输入 → 输出 | 怎么用 |
|---|---|---|---|
| `ark.py` | 火山方舟：Seedream 出图、Seedance 出视频（异步任务 + 轮询 + 立刻下载） | 提示词 + 参考图 / 音频 → 图片或视频 + 同名 `.json` 记录 | `ark.image(...)`、`ark.video(...)`；素材项 `ark.img()` / `ark.aud()` / `ark.vid()`。见 `生成工具怎么用.md` |
| `tripo.py` | Tripo V3：文 / 图 / 多视图生 3D、绑骨、套动作、转格式、减面、重贴图、查余额 | 提示词或图片 → glb（或 fbx）+ 预览图 + `.json` 记录 | `tripo.text_to_model(...)` 等；预设 `draft / character / final` |
| `sensorium.py` | 感官层：把音频拆成 心跳 / 威胁 / 饥饿 / 张力 / 节律 五路 0~1 的信号 + 起音和拍点 | 音频 → 每帧一组数 | 一般不直接用，跑 `tools/sense_song.py` |

## tools/ —— 直接在命令行跑的脚本

### 听（把音乐拆开）
| 文件 | 干什么 | 输入 → 输出 | 命令 |
|---|---|---|---|
| `sense_song.py` | 整首歌过一遍感官层 | 歌 → 作品/`感官.json` + `感官_条带.jpg`（一眼看通道对不对得上段落） | `python tools/sense_song.py [音频] [--out 目录]` |
| `separate.py` | Demucs 分四轨 | 歌 → 作品/`分轨/{drums,bass,vocals,other}.wav` | `python tools/separate.py [音频] [--out 目录]` |
| `beats.py` | beat_this 找拍点和每小节第一拍；给乐句格子起点就顺便做交叉校验 | 歌 → 作品/`节拍.json` | `python tools/beats.py [音频] --grid 13.11 --bars 4` |

### 看 / 抠
| 文件 | 干什么 | 输入 → 输出 | 命令 |
|---|---|---|---|
| `matte.py` | BiRefNet 抠像（逐帧，视频会轻微闪） | 图 / 图片目录 / 视频 → `<名>_alpha.png`（或 `<名>_alpha/` 目录）；`--rgba` 再出带透明的抠图 | `python tools/matte.py 输入 [--rgba] [--every N]` |

### 生成（花钱的）
| 文件 | 干什么 | 输入 → 输出 | 命令 |
|---|---|---|---|
| `emotion_board.py` | 情绪大图：全曲按段一格（图 + 时间 + 一句「她此刻」+ 这一段的感官曲线） | 作品/`情绪大图/草案.json` → 每段一张 `NN.jpg` + 拼好的 `_情绪大图.jpg` | `python tools/emotion_board.py --gen [--only 04,05] [--mdl seedream_flash]`；不加 `--gen` 只重新排版、不花钱 |

### 剪（纯文字剪辑表）
| 文件 | 干什么 | 输入 → 输出 | 命令 |
|---|---|---|---|
| `edl.py` | 纯文字剪辑表 + 不叠效果的快速预览（480p，整首约 20 秒出） | `export`：→ 作品/`剪辑表.txt`；`preview`：剪辑表 + 原曲 → 作品/`样片/预览_剪辑表.mp4` | `python tools/edl.py export [--force]` / `python tools/edl.py preview` |
| `fx_footage.py` | 把数学效果直接作用在剪辑表的画面上：`dct`（breakdown 的记忆被压缩，系数跟「饥饿」走）、`droste`（卷成无限螺旋） | 剪辑表 + 原片 → 作品/`样片/段落试验_*.mp4` | `python tools/fx_footage.py dct [--from 153.91 --to 173.11]` |
