# 换电脑怎么复现（2026-10-22）

> 一句话：**代码和做法都在 git 里，能复现；但两个仓库都还没有远端备份，大文件（视频、模型、素材）不进 git，换电脑要整个文件夹拷走。**

## 要带走的东西
| 东西 | 在哪 | 在 git 里吗 |
|---|---|---|
| 代码、自检、效果库、人读说明 | `Vault_Automata/4_Eidolon/` | ✅（本地 git，**没有远端**） |
| 作品数据：感官.json、锚点.json、剪辑表、物件表、静帧、sidecar | `Projekt_Visual/MV_Cant_Kill_Us/` | ✅ 大部分（本地 git，**没有远端**） |
| 视频（样片、生成、素材）、3D 模型 .glb、分轨 wav、cache | 同上 | ❌ `.gitignore` 排除了 → **要整个文件夹拷** |
| 原曲 | `Projekt_Visual/Assets/` | ❌ |
| 密钥 | `4_Eidolon/config/creds.local.json` | ❌（故意不进 git；换电脑手动拷，或重新填） |
| Python 环境 | `4_Eidolon/.venv`（Python 3.12.7） | 依赖清单 `requirements.lock.txt` ✅ |
| 模型权重 | `~/.cache/huggingface/hub/`（BiRefNet、HTDemucs）、`~/.cache/torch/hub/checkpoints/beat_this-final0.ckpt` | ❌（第一次运行会自动下载） |
| Blender 5.2 | `E:/2_Wares/Blender Foundation/` | ❌（只有 `blender_pose.py` 用，已弃用） |

## 新电脑上
1. 拷 `Vault_Automata/4_Eidolon/` 和 `Projekt_Visual/` 整个文件夹（含视频）。
2. 装 Python 3.12 → `python -m venv .venv` → `.venv/Scripts/python -m pip install -r requirements.lock.txt`（torch 是 CUDA 12.8 版，需要 NVIDIA 显卡和对应驱动）。
3. 拷或重填 `config/creds.local.json`。
4. 跑自检：`.venv/Scripts/python -m unittest discover -s tests -q`（全绿 = 环境对了）。
5. 每个效果怎么重出：看 `-给人类的解释/工具一览.md` 和各效果的「怎么做的.md」；每个样片旁边的 `.json` sidecar 记了当时的参数。

## ⚠️ 不能完全一样复现的
- **Seedream / Seedance 生成的**：同样的提示词不会再出一模一样的图和视频 → 生成物本身就是原件，要保管好（`生成/`、`素材/`）。
- **随机种子**：我们的算法大多固定了 seed，sidecar 里有记录；个别早期样片没记，重出会略有不同。
- **GPU 不同**：浮点细节可能差一点点，肉眼看不出。

## 建议（等👤定）
- 两个仓库加一个**私有**远端（GitHub 私有库或 NAS），代码和文档至少有一份异地备份。
- 视频和模型用移动硬盘 / NAS 定期整盘备份。
