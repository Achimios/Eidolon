## 1. Seedream 5.0（出图）—— flash 打草稿，pro 出精图

**干什么用**：一句话（+ 参考图）出一张静帧。草图、角色设定图、情绪大图的每一格、给 Seedance 当首帧。

| | flash | pro |
|---|---|---|
| 用途 | 草图、快速试方向（情绪大图就是 flash 出的） | 定稿静帧、角色设定图（「她」的设定图 `角色_她_正面_灰_pro.jpg` 是 pro 出的） |
| 参考图 | 最多 **10 张** | 最多 **10 张** |
| 速度（我们的感觉） | 约 10–15 秒一张（情绪大图 4 张并行，文件时间戳大约每 10 秒落一批）—— 精确单张耗时【没验到】 | 约 40 秒一张【没验到：没留计时记录】 |

**能做的事**
- **参考图**：本地图直接传（封装会转成 base64）。提示词里叫它们「图1、图2……」：「图1 的构图、图2 的光」。
- **尺寸**：`"1K" / "1.5K" / "2K"`，或直接写 `"宽x高"`。21:9 可以用 `"2560x1096"`。官方说 1.5K 和 1K 同价、效果更好。
- **图层拆分**（`layer_decomposition=True` + 一张图）：拆成底图 + 最多 16 张透明 PNG 图层 → 可以在 Blender 里一层层摆深度，做 2.5D 视差。【没验到：我们还没跑过】
- **透明背景**（`background="transparent"`）：只限图生图，输入要是一张带透明通道的 png。【没验到】
- 提示词：中文 ≤300 字，太长会丢细节。

**最小例子**

```python
# 草图（flash），带一张参考图
ark.image("纯黑画面正中一条极细的水平光线……", "D:/out/草图.jpg",
          mdl="seedream_flash", size="1920x1080",
          refs=["静帧/01_delay_embedding.jpg"])

# 精图（pro），多张参考图保持角色一致
ark.image("图1、图2 是同一个全息女性 AI，保持她的脸……", "D:/out/设定.jpg",
          mdl="seedream_pro", size="2560x1440",
          refs=["记忆帧/m40.jpg", "记忆帧/m02.jpg", "静帧/09_optimal_transport.jpg"])

# 图层拆分（多出来的图层自动存成 设定_layerN.png）【没验到】
ark.image("拆成前景人物、中景、背景", "D:/out/拆.png", mdl="seedream_pro",
          refs=["D:/out/设定.jpg"], layer_decomposition=True, output_format="png")
```

`mdl` 填的是别名（`seedream_flash` / `seedream_pro`），真实模型名在 creds 里的 `models` 表。

## 2. Seedance（出视频）—— 用 2.5，先 480p 样片再出正式

⚠️**整个 Seedance 这一节，我们的封装 `ark.video` 还一次都没真跑过**（作品文件夹里没有任何 Seedance 的生成记录）。下面的能力全是官方文档写的，第一次用时请盯着看。【没验到】

**干什么用**：出 4–30 秒的视频镜头。三种喂法，**互斥、不能混用**：
1. **首帧**：给一张图当第一帧。
2. **首尾帧**：给开头和结尾两张图，中间的变化交给模型 —— 这正好是我们的「锚点」语法：开头她什么样、结尾她什么样。
3. **全模态参考**：一堆参考图 + 参考视频 + 参考音频，模型自己综合（想要首帧就在提示词里说「以图片1 为首帧」，但不保证严格一致）。

| | 2.5（我们用这个） | 2.0 / 2.0 fast |
|---|---|---|
| 时长 | 4–30 s | 4–15 s |
| 参考图 | 1–30 张 | 1–9 张 |
| 参考视频 | ≤10 个，总 ≤30 s | ≤3 个，总 ≤15 s |
| 参考音频 | ≤10 段，总 ≤30 s，**可以只给音频** | ≤3 段，总 ≤15 s |
| 分辨率 | 480p / 720p / 1080p | 2.0 到 4k；fast 只到 720p |
| 画幅 | 有 **21:9**；⚠️首帧 / 首尾帧模式只能 `adaptive`（跟图的比例走） | 都能指定 |
| 样片模式 | ✅ `draft=True` 出 480p 预览，满意后用它的 task id 出正式版（继承构图和运镜，7 天内有效） | 没有 |
| 输出 | mp4，或 **mov（yuv444p，适合调色 / 抠像 / 合成 —— Zaoeyo 后期要的就是这个）** | mp4 |
| 接镜头 | `return_last_frame=True` → 额外存一张尾帧 `xxx.mp4.last.jpg` → 当下一段的首帧 | 同 |

**几个坑**
- **视频参考只能给公网 URL**（或 `asset://`），不能直接传本地文件。图片和音频可以本地传。
  → 用 Blender 做的镜头指导，暂时先渲成**首帧 / 首尾帧图片**传（方舟 Files API 能不能替代公网地址【没验到】）。
- 默认会生成声音，我们的封装已经默认关掉（`generate_audio=False`）—— 音乐用原曲。
- 不接受真人人脸。

**最小例子**

```python
# 首尾帧，480p 样片
p = ark.video([{"type": "text", "text": "她从完整到碎裂，镜头缓慢推近"},
               ark.img("生成/她_完整.jpg", role="first_frame"),
               ark.img("生成/她_碎裂.jpg", role="last_frame")],
              "D:/out/镜头04_样片.mp4", mdl="seedance_25", ratio="adaptive",
              duration=5, draft=True, return_last_frame=True)
# task_id 记在 D:/out/镜头04_样片.mp4.json 里

# 全模态：参考图 + 这一段原曲（画面跟音乐走）
ark.video([{"type": "text", "text": "……"},
           ark.img("生成/角色_她_正面_灰_pro.jpg"),       # 默认 role = reference_image
           ark.aud("分轨/drums_51-60.wav")],               # wav / mp3，单段 ≤15MB
          "D:/out/镜头04_全模态.mp4", ratio="21:9", duration=8, draft=True)

# 样片满意 → 出正式版（按官方文档的写法；封装还没专门包这一步）【没验到】
ark.video([{"type": "draft_task", "draft_task": {"id": "<样片的 task_id>"}}],
          "D:/out/镜头04_正式.mov", ratio="adaptive", resolution="1080p", output_format="mov")
```

## 3. Tripo（出 3D 模型）

**干什么用**：一句话 / 一张图 / 几张多视角图 → 3D 模型（glb）。还能自动绑骨、套预设动作、转格式、减面。
在我们这里有两种用法（👤2026-10-20）：
- **镜头指导**：白模在 Blender 里摆机位、走位、打光（潦草也行）→ 渲出首帧 / 首尾帧 → 交给 Seedance 补质感。
- **成片**：模型直接在 Blender 里渲染（还能出深度 / 遮罩 / 运动矢量给现场用）。

**⚠️钱的事**
- **API 积分和网页版会员点数是两个账户。** 网页订阅的点数 API 用不了；API 积分要另外领 / 买。1 credit = 0.01 美元。失败的任务不扣钱。
- 当前 API 余额：约 990（领了 1000，试跑花了 10）。

**实测过的**：文生白模（`draft` 预设：无贴图、1 万面）= **10 积分、131 秒**，出一个 300KB 的 glb + 预览图。
→ `Projekt_Visual/MV_Cant_Kill_Us/3D/测试_人台.glb`。其余功能（绑骨、动作、贴图、转格式）都还没真跑过【没验到】。

| 预设 | 干什么 | 价格（官方价目表） |
|---|---|---|
| `draft` | 白模，镜头指导用 | 文生 10 / 图生 20 |
| `character` | 带贴图、要绑骨做动画的角色 | 生成 20–30 + 绑骨 25 + 每个动作 10 |
| `final` | 静态成片资产，PBR + 高清贴图 + 精细几何 | 文生约 50 / 图生约 60 |

**绑骨 / 动作的顺序**：生成 → （减面、分件、转格式都在这一步之前做完，否则会丢骨骼）→ `rig_check`（免费）→ `rig` → `retarget`。
人形绑骨用新骨架 `v3.0-20260909`：质量好但只有 11 个动作；要跳舞 / 情绪类动作得用老骨架 v1.0（90+ 个）。
⚠️要绑骨就**别设朝向参数**（会静默转错，任务还显示成功）。

**最小例子**

```python
# 文生白模（实测过）
path, task = tripo.text_to_model("a simple low poly humanoid mannequin in A-pose",
                                 "D:/out/人台.glb", preset="draft")

# 图生角色 → 绑骨 → 套动作【没验到】
path, t = tripo.image_to_model("生成/角色_她_正面_灰_pro.jpg", "D:/out/她.glb", preset="character")
print(tripo.rig_check(t["task_id"]))                       # 免费
rp, rt = tripo.rig(t["task_id"], "D:/out/她_rig.glb")      # 25 credit
tripo.retarget(rt["task_id"], ["preset:idle", "preset:walk"], "D:/out/她_动作.glb")  # 每个 10

print(tripo.balance())   # 查余额，不花钱
```

**CLI 还是 `src/tripo.py`？**
- 官方命令行 `tripo-cli`（已全局装好，`tripo doctor` 全过）：适合**手动试一下**、`--dry-run` 先看会花多少。
- `src/tripo.py`：适合**流水线**（脚本里批量跑，会自动下载、写 sidecar 记录）。
- ⚠️Tripo 的 V2 接口 2026-11-01 停用，我们只走 V3。

**Neural4D（另一家，2026-10-22 接上）**：`src/neural4d.py`，参数和与 Tripo 的对比见 `_设计/接口_Neural4D.md`。默认就出灰模、能出四边面（OBJ）、一次最多 4 个变体；但**没有绑骨、没有「同一几何补贴图」**，三角面最低 10 万。查余额 `neural4d.balance()`（免费，当时 4945 点）；真生成一次文档示例价约 30 点【没验到】。

## 5. 什么时候用哪个（一句话版）

- 想**试方向** → Seedream flash，几秒一张，多出几张挑。
- 方向定了、要**定稿 / 定角色** → Seedream pro，带上之前的设定图当参考。
- 要**动起来** → Seedance 2.5：先 `draft=True` 出 480p 看构图和节奏，满意再出正式（要后期就出 mov）。
- 要**严格控制构图和运动** → Tripo 白模 + Blender 摆好 → 首帧 / 首尾帧交给 Seedance。
- **碎裂 / 重组这类「每个点都要有意义」的镜头** → 不交给生成模型，用我们自己的粒子代码算（`tools/particle_*.py`）；生成模型只负责「她长什么样」。
- 要**跟着音乐** → 先用 Demucs / beat_this / 感官层把歌拆开，所有规则读这些真数。
