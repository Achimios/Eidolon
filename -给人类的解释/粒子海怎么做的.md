# 粒子海怎么做的（`tools/particle_sea.py`）

> 参考图：`Projekt_Visual/_参考库/2026-10-21_用户给的/粒子海_鲸.webp`（👤 2026-10-21 给的：线框的鲸从点阵的海里跃出，旁边是荧光绿的 UI 块）。
> 样片：`Projekt_Visual/MV_Cant_Kill_Us/样片/粒子海/`。纯 numpy，**在 CPU 上跑，不占 GPU**。
> 自检：`tests/test_particle_sea.py`（15 项）。

## 一句话

一片真实起伏的海（海洋学里的波浪谱算出来的），海面上撒着几十万个随水起伏的小短划；她是一张贴着身体曲面的线框，由这片海里的点一粒一粒飞上去拼成 —— 每一个起音吞一口海，并在她脚下打出一圈真实的水波。

## 先拆参考图（我量了什么）

| 看到的 | 量出来的 | 它其实是什么 |
|---|---|---|
| 海是一颗颗**短划**，不是圆点 | 短划长约 2–3 px、粗约 1–2 px（参考图 736 px 宽）；方向在一片区域里大致一致，跟着海面走 | 每个点 = 水面上的一小段（像一张贴在水面上的网格被拆成了碎段）。短划的方向 = 水面的走向 |
| 海的「亮线」 | 亮度主要来自**点挤在一起**，不是打光：近处海面 575 个亮点 / 万像素（间距 4.2 px），中景 337（5.5 px），远处 399（5.0 px）；像素中位亮度只有 0.09–0.16，亮的 1 % 才到 0.8 | 波峰被斜着看时，透视把一大片点压成一条线 → 亮线；浪的背面被前面的浪挡住 → 黑。**亮 = 投影密度** |
| 鲸 | 方格网，格距约 4.5 px；顶上亮、侧面暗，轮廓边上格子变密 | 曲面上的网格线（类似 3D 扫描的线框），亮度 = 光照 × 网格在斜面上被压密 |
| 底色 | 背景灰 0.16（不是纯黑），白的部分偏中性灰 (0.75, 0.75, 0.76) | —— |
| 绿块 | 荧光绿 (0.55, 0.85, 0.12) 占画面 6.7 % | **UI 装饰**。不说真话 → 我们不做。配色见下面「颜色 = 状态」 |

## 我们怎么做（每一步都是真算的）

| 步 | 做什么 | 为什么这样 |
|---|---|---|
| ① 海 | **Tessendorf FFT 海**：JONSWAP 波浪谱（海洋学测出来的风浪能量分布，给有效波高 Hs、峰值周期 Tp）+ 方向扩展 cos^2s + 深水色散 ω = √(gk)（长浪跑得快、短浪慢）+ 水平 choppy 位移（波峰变尖、波谷变平 = Gerstner 浪的推广） | 符号说真话：浪的形状、速度、尖锐程度都来自物理，不是噪声。HUD 上的 Hs / Tp 是真参数 |
| ② 海上的点 | 点固定在水上（跟着水一起转圈 —— 拉格朗日标记）。撒点密度 ∝ 1 / 到镜头距离²（像从镜头那里做的激光雷达扫描：近处疏、远处密，平静水面在屏幕上大致均匀） | 这样屏幕上「哪里亮」只剩坡度和遮挡在决定 —— 和参考图的机理一样 |
| ③ 短划 | 每个点画成一小段：沿水面切向的一小截 + 曝光时间里镜头移动拖出来的那一截 | 镜头快的时候短划长、慢的时候短 —— 先快后缓的运动直接写在海的纹理里 |
| ④ 遮挡 | 深度缓冲：被前面的浪挡住的点不画；被她挡住的海不画；她在水面以下的部分不画（按那一点真实的水面高度判） | 浪背的黑带就是这么来的 |
| ⑤ 她 | 模型 `3D/N4D_蜷缩抱膝_无材质_100万面.glb`（👤用 Neural4D 做的蜷缩抱膝）表面撒点，只留落在两族等距平面上的 → 一圈圈横环 + 一条条斜的竖线 = 贴着曲面的网格；背面剔除、顶光兰伯特、轮廓边缘提亮 | 形体来自真实模型（低熵注入）；线框和参考图的鲸是同一个读法 |
| ⑥ 吸收 | 她身上每一个点，原本都是她脚下周围那片海里的一个点。到它的释放时刻，就从水面按**临界阻尼弹簧**飞向自己在线框上的位置（闭式解，不过冲，先往上抛再收进来） | **质量守恒**：海 + 飞行中 + 已到达 = 常数，HUD 逐帧写这三个数；她周围那片海会被吸稀 —— 看得见的代价 |
| ⑦ 跟着音乐 | 每个起音放一批：批的大小 ∝ 威胁³（强拍一口吞一大片，弱拍零星几粒），另有 10 % 的细流；谁先走 = 离水面高度（低的先走，加点抖动）→ 她从海里往上长 | 拍点作用在有形的东西上：**不推全局放大、不抖画面** |
| ⑧ 环形波 | 每个起音在她脚下打出一圈 **Cauchy–Poisson 波**（深水里「一块水面突然隆起又放开」的精确解：η(r,t) = ∫ k η̂(k) J0(kr) cos(√(gk) t) dk）。振幅 ∝ 威胁 | 真色散：短波跑在前面、长波在后面，一圈圈散开。自检用另一种独立方法（2D FFT 直接演化）对过，误差 < 1 % |
| ⑨ 红点 | 全片唯一的红：最强那一拍放出的点里，落在她胸口附近的一个；它的飞行时间单独算，让它**正好在下一个小节首拍到达**（晚一拍） | 「心」最后回来 |
| ⑩ 镜头 | 不从静止开始：沿路径的路程 s(t) = v_b·t + v₀τ(1 − e^{−t/τ})，进来时很快，指数地缓下来但不停；低机位、轻微倾斜，她在画面右侧 | 先快后缓（👤 §四⅞¾）；仰视让她显得巨大，像参考图里的鲸 |

## 「必须相等」的量（自检里验的）

- 4 × 海面高度的标准差 == 给定的 Hs（8 个随机种子平均，误差 < 8 %）。⚠️第一版就是这里抓到 bug：谱的每个模被 k 和 −k 算了两次，实际浪高是设定值的 √2 倍。修了之后，为了保持看过的那种气势，默认 Hs 从 8 改成 10（真的 10 m，HUD 写的也是 10）。
- 单个波模 == 0.7·cos(kx + √(gk)·t)，逐格点（色散关系没写错）。
- 环形波：t = 0 时精确是高斯隆起；t < 0 时为 0；t = 2.5 s 时和 2D FFT 直接演化的剖面一致（误差 < 1 % 振幅）。
- 质量守恒：任意时刻 海 + 飞行 + 到达 == 总数。
- 红点到达时刻 == 最强起音后的第一个小节首拍。

## 和参考图不一样的地方（故意的 / 没做到的）

- 不做绿色 UI 块、二维码、小字装饰；HUD 只有底部两行真数字。
- 参考图背景是深灰，我们用近黑（本片配色）。
- 参考图的鲸格线是「沿身体走」的（像建模的布线）；我们的线是平面切出来的等高线 + 斜线，曲面弯的地方会形成同心的弧（像地形图）。

## 颜色 = 状态（两套配色，一次模拟同时出）

| 配色 | 海 | 被起音推起来的水 | 正在飞向她的 | 已经是她的 | 那一个点 |
|---|---|---|---|---|---|
| ① 黑白红（`bwr`） | 冷灰白 | 冷灰白 | 冷灰白 | 冷灰白 | 红 |
| ② 酸绿（`acid`，👤 2026-10-22 允许酸性点缀） | 很暗的冷灰 | 酸绿 | 酸绿 | 白 | 酸黄 |

②的意思：酸绿 = 外来的东西（残响）。它从海里被拽起来时是绿的，一落到她身上就褪成白 —— 颜色本身就在说「吸收」。所以绿只出现在**正在发生**的地方，画面大部分时间仍是黑和灰。

- 「海面下远处很暗地隐约有一个巨大形体（鲸 / 更大的她）」：**没做**。我们的海是「水面以下看不见」的模型（遮挡就是这么算的），硬画一个水下的影子要另编一套透光规则，不说真话；而且 v3 的束已经占了画面里的「事件」，再加一个大形体会抢她。要的话可以在远处海面上**露出**一个很暗的线框背脊（同一套渲染，只是很远很大），等用户定。

## 试过、放弃的

- 「只有海」的镜头（`body=0`）：没有她，只在海上不同地方冒出环形波 = 「四周全是别的声音」。高机位、低机位各试一次，**都是满屏纹理、没有形**（正是「too cheap, no form」）→ 放弃。海需要一个主体。

## 没做到 / 没验到

- 吸收点的起飞位置用的是「当前时刻」的水面（不是释放那一刻的），所以飞行中的弧线会跟着脚下的浪轻微摆动（量级 < 浪高）。
- 环形波只有竖向位移，没有水平轨道运动；也没有和 FFT 海做非线性耦合（线性叠加）。
- 没有真的听过：节奏感、「一口一口」的力度对不对，要用户看视频判断。
- 我看的是接触表和抽帧，看不到连续运动里有没有闪烁（深度缓冲是低分辨率格子，浪边缘的点可能逐帧跳）。
