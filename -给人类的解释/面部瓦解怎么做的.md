## 方法一：7 步（每一步是代码里的一个函数）
先把她往右挪 180 像素（参考图里脸在右边，左边全是拖影）。轮廓来自 BiRefNet 抠像，每帧一张。

| # | 函数 | 画面上是什么 | 怎么算的 | 旋钮 |
|---|---|---|---|---|
| 1 | `band_displace` | 整张图被切成几条横带，有几条整条往左（偶尔往右）错开 | 每条带的高度随机（几何分布）；错多少是「重尾」的：大部分错一点点，偶尔错很远（Pareto 分布） | 带的条数 `n_bands`、最远错多少 `max_dx`、每条带被错开的概率 `p_shift` |
| 2 | `row_smear` | 脸的左边拉出很长的横条纹 | 每一行取「轮廓往里一点、最亮的那个像素」的颜色，往左一直拉；离轮廓越远越暗（指数衰减），中间随机断几截。起点按横带对齐，所以拖影起点是一级一级的台阶 | 拖影长度 `smear_len`、断开的比例 `smear_dropout` |
| 3 | `pixel_sort_rows` | 拖影里的像素被「理顺」，亮的靠右、暗的靠左 | 每行里亮度在 [lo, hi] 之间的连续一段按亮度排序（像素不增不减，只换位置） | `sort_lo`、`sort_hi` |
| 4 | `channel_split` | 轮廓外面一圈红，里面一圈绿 / 蓝 | 红、绿、蓝三个通道沿轮廓的法线方向各自推开不同的距离 | 三个距离 `split_d`（红往外推、绿蓝往里） |
| 5 | `column_jitter` | 脸里面全是竖着的扫描纹 | 脸里每一列上下错几个像素、亮度随机打折；红绿蓝各错各的，所以灰脸上也会出彩色竖纹 | 最大错位 `jitter_amp`、条纹深浅 `jitter_gain` |
| 6 | `macroblocks` | 背景里散落的「蓝绿红」三根小竖条 / 小横杠，还有几块马赛克 | 对齐到 16 像素网格画三联条；马赛克 = 一块 16×16 只剩平均色（视频压缩里的「只剩 DC」） | 网格 `grid`、三联条数量、马赛克块数 |
| 7 | `channel_ops` 等 | 少数横带里脸换了颜色或反相；颜色变成几级；脖子肩膀过曝成白；背景灰尘、划痕；左边一条红竖条 | 通道置换 / 反相（只在她身上）、色阶量化、底部增益后截断、随机亮点 | 置换 / 反相概率、色阶数 `levels`、过曝起点 `clip_y0` |

## 方法二：瀑布图行（`waterfall_rows`）—— 为什么说它是「瀑布图」
瀑布图 / 频谱图的规矩是：**一个方向是时间**。这里把横轴当时间：

- 每一帧，记下「每一行轮廓往里一点的那个像素」——一根竖着的像素柱，存进历史（`BoundaryHistory`）。
- 画第 y 行时，轮廓左边第 d 个像素 = **d ÷ 6 帧之前**那根柱子在第 y 行的颜色。
- 所以左边的拖影不是一条单色的线，而是**这一行过去 2 秒的录像**被横着摊开：她抬头、横带错开过，这些都会在拖影里留下痕迹（像狭缝摄影 slit-scan）。

和方法一的区别：方法一的拖影是「此刻」的颜色拉长；方法二是「过去」排成一排。看 `23d` 和 `…_瀑布图行_本片.mp4`。
⚠️视频的前约 2 秒历史还没攒满，拖影是慢慢长出来的。

## 声音怎么驱动它（感官.json → 参数）
| 感官通道 | 控制什么 | 公式 |
|---|---|---|
| 威胁 threat | 横带条数 / 最远错开 / 错开概率 | 条数 = 4 + 22·威胁；最远 = 16 + 300·威胁 像素；概率 = 0.25 + 0.5·威胁 |
| 张力 tension | 红绿蓝分离的距离 | d = 2 + 16·张力（红 +d，绿 −d/2，蓝 −d） |
| 饥饿 hunger | 拖影长度 | 40 + 520·饥饿 像素 |

随机种子每 4 帧换一次，强起音（这段里威胁最高的 12%）那一帧一定换 —— 所以「碎法」会跟着鼓点跳。
视频左下角小字和同名 `.json` 写的都是每一帧真实用到的数。
⚠️感官.json 从 2026-10-21 起已经是**播放时间**（上游在源头补了 42 ms），不用再加偏移；`--sense-offset` 默认 0。

## 时间包络：什么时候开、开多大（`envelope`，加 `--envelope`）
用户的判断：**这个效果很暴力，不能一直开着。** 所以前面只在几个强鼓点上「闪」一下，到最后才整段全开。
门控 g 在 0（干净的她）到 1（完全瓦解）之间，每帧一个值，规律是：

- **脉冲（前段，稀疏）**：起音那一帧附近的「威胁」峰值 s ≥ 0.5 才触发。幅度 = 0.6 + 0.4·(s−0.5)/0.5（越猛越接近 1），
  满幅停 2 帧，然后每帧乘 e^(−1/1.5) 很快退掉。威胁不够的起音不触发。
- **收尾（持续）**：镜头结束前 1.8 秒开始（如果 ±0.2 秒内有小节首拍，就对齐到那一拍），用 0.4 秒平滑地升到 1，然后一直全开到镜头结束（这里是 1.4 秒）。
- 两者取大。⭐**g 是效果强度，不是透明度**（👤 v3 起）：g 小于 1 时，每一步的力度都按 g 缩小 —— 横移距离、RGB 分离、拖影 / 瀑布图的长度和亮度、竖纹、色块数量、换通道、过曝、灰尘、左边红条、色阶数。画面始终完全不透明：弱的脉冲就是「轻轻地碎一下」，不是「半透明地叠一层」。g = 0 时整条流程等于什么都没做（自检逐像素查过）。v2 用的是和干净帧交叉淡化，已经废掉。

⭐**v4（当前）**：`样片/17_面部瓦解_全息女性_v4_瀑布图行_本片_45.12-51.52_v2.mp4`（另有 `…_v4b_瀑布图行_本片_45.12-51.52_满2s_v2.mp4` 对比；不带 `_v2` 的两个是第一遍：停住那段种子每 4 帧才换，结尾约 0.3 s 每 4 帧顿一下、近似定格 → `_v2` 在停住的帧上每 2 帧换种子 `--hold-held 2`）。和 v3 的区别：
- **构图**：头放在画面右边（头中心在画宽 0.64 处），左边约 45 % 是给拖影 / 瀑布图行的空间 —— 像最早那张 03 抬头的试帧。源：`素材/全息女性视频运镜描述_裁肩_v2.mp4`（同样 995×559 → ×1.29 Lanczos、平滑跟头；框出了源画面就补黑，不拉伸 —— 这段实际没出界）。
- **不变速**（👤）：她按原速播 5.04 s（45.12 → 50.16），然后停在最后一帧 1.36 s 直到 51.52 的切点。停住的那段正好在全开里：横带、RGB 分离、瀑布图行都还跟着音乐在变，所以读起来不像定格。（另一种做法是把开始推后 0.14 s、停满 1.5 s；我选了从 45.12 开始、停 1.36 s，让开头的第一下脉冲 45.15 还在镜头里。）
- **收尾**：v4 = 49.55 起升、49.95 起全开（≈1.6 s）；v4b = 49.12 起升、49.52 起全开整 2.0 s。

- **全面抹除**（👤：不是变黑，是**效果开到最大、把整张画面均匀地扫成一片亮的拖痕**）：最后 8 帧（51.20 → 51.52，在镜头里面，不加长、不动切点）。
  每一行有一条扫描前沿，从脸的左边缘扫到画面最右一列就停（不出画）；各行出发时间只差 0–12 %（比第一版齐）。
  前沿扫过的路上最亮的那个像素被「锁住」，前沿左边整行变成这个颜色往左拉（拉的长度从 200 像素长到几乎不衰减，带一点粗颗粒纹理），而且只会变亮、不会变暗；没有整体压暗。
  结果：u≈0.9 时脸已经没了，最后一帧是一整片亮的横向拖痕（画面平均亮度从 0.26 升到 0.67）。
  抹除之前的帧直接从已有成片里逐帧拿（接缝那帧重算比对，平均差约 1.7/255 = 编码噪声）。
  文件（`样片/面部瓦解/`）：`17_面部瓦解_全息女性_v4_瀑布图行_本片_45.12-51.52_抹除_v2.mp4`、`…_v4b_…_满2s_抹除_v2.mp4`，各有 `_末0.6s接触表.jpg`。
  不带 `_v2` 的 `…_抹除.mp4` 是第一版（扫出画 + 压暗到黑，最后 3 帧几乎全黑）—— 理解错了，留着对比。命令：`--wipe 0.35 --wipe-mode even`（`dark` = 第一版）。
- **v4c**（同 v4 + 抹除 v2，另修两处）：
  · 红边不再每帧都有：红的强度 = smoothstep((门控 − 0.6)/0.4)，只在强脉冲和收尾全开时出现（`--red-gate 0.6`）。
  · 底部偶尔出现的硬边白块（横带把遮罩切成矩形 × 底部过曝 × 硬截断）：过曝用的遮罩先模糊 12 像素，亮部用软肩压而不是硬截到 1（`--soft-clip 12`），所以不会出现死白的平块。
  文件：`样片/面部瓦解/17_面部瓦解_全息女性_v4c_瀑布图行_本片_45.12-51.52_抹除_v2_白块再修.mp4`（⭐用这个）。
  `…_v4c_…_抹除_v2.mp4` 是第一遍：只模糊了遮罩、软肩从 0.8 起，白块只少了一半多 → 再修版把软化模式下的过曝增益和加亮都减半、软肩从 0.7 起。
  实测（前 146 帧、画面下部）：亮度 > 0.9 的平白面积 v4 0.58 % → 0.04 %；每帧「亮区的硬水平边」像素 21 → 3。
  ⚠️没根治：剩下的硬边是横带把本来就亮的脖子 / 衣领整块错开造成的（内容本身的边），偶尔还能看到一块偏亮的矩形，只是不再是死白。
  红边：前 105 帧（全开之前）出现红的帧从 36 帧降到 4 帧（都是 ≥ 0.6 的强脉冲）。

v3（已被 v4 取代）：`样片/17_面部瓦解_全息女性_v3_瀑布图行_本片_45.12-51.52.mp4`，整个乐句 45.12 → 51.52 s，最后一帧直接切进碎裂冲击。
- 源先裁紧到肩（`素材/全息女性视频运镜描述_裁肩_v1.mp4`，对比图 `…_裁肩_v1_对比.jpg`）：裁 995×559，放大 1.29 倍（Lanczos），头宽 / 画高对齐 03 抬头那个镜头；裁切框跟着头顶和头的水平中心走，高斯平滑 10 帧，不抖。⚠️她头发比 03 的模型蓬，按头宽对齐后脸本身比 03 小一点；镜头末尾肩膀出画。

- 节奏：前面 6 下脉冲（45.15、45.95、46.75、48.35、48.75、49.15），49.55 开始升（这里有个强起音；49.92 / 49.96 那两个候选点没有起音），49.95 起全开到 51.52（约 1.6 s）。

```
       --start 45.12 --envelope --ramp-start 49.549 --place-dx 0 --name "17_面部瓦解_全息女性_v3_瀑布图行_{pal}_45.12-51.52"   # v3
python tools/face_glitch.py reframe 作品/素材/全息女性视频运镜描述.mp4 --head-x 0.64 --ver v2   # 头在右
python tools/face_glitch.py clip --src 作品/素材/全息女性视频运镜描述_裁肩_v2.mp4 --src-t0 0 --dur 0 --extend-to 6.4 \
       --start 45.12 --envelope --ramp-start 49.549 --place-dx 0 --name "17_面部瓦解_全息女性_v4_瀑布图行_{pal}_45.12-51.52"   # v4
python tools/face_glitch.py image 任意图.jpg [--mask 遮罩.png] [--palette ours]   # 没遮罩就用亮度阈值
```
