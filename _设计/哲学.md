# 哲学（👤用户原话 + 落地方式）

> ⭐这是 Eidolon、VisualProcess、Synapsis、NPC、游戏设计、电影语言**共用的地基**。新会话接手先读这份。
> 原话保留（中英混合照抄），后面是「在工程里长什么样」。改这份 = 改判据，👤逐条过。

## 1. 涌现的自构建：锚点 + 规则（2026-10-19）
> 「记住涌现的自构建基础，我提供情绪和画面锚点，规则涌现画面和运动。」

- 人给**少量高信息**的约束：情绪锚点（拍点、情绪曲线、「这里该切」）+ 画面锚点（定稿静帧、手标区块、概念图）。
- 规则（Kuramoto、反应扩散、DLA、沙堆、最优传输、吸引子……）在锚点之间生成画面和运动。**中间不手 K。**
- 规则参数由锚点驱动：K 跟拍点，r 跟情绪曲线，最优传输的目标 = 下一个画面锚点。
- 用户没给锚点的地方：问，或者留给规则自由演化 —— 不脑补一条精确曲线。
- 落地：`Projekt_Visual/<作品>/锚点.json`（by:user = 真源）、`规则/剪辑规则.json`。

## 2. 人类的低熵注入（2026-10-15 起，10-19 推广）
> 「Emotions link them, construct one from other. Human low entropy inception.」

- 程序噪声是回退；真实记录、有模式的图片、人的手势 / 耳朵 / 情绪才是源。
- **用户的耳朵是校准器**：13.08 / 19.5 两个切点 → 吸附到起音 → 推出 6.4 s 乐句格子，整首歌的 drop / breakdown / outro 全对上（误差 ≤ 1.1 s）。人给两个点，规则铺满全曲。
- 感官系统要学会「用用户的方式听」：用户标少量时刻，拟合「特征 → 用户的情绪」。

## 3. 感知 → 解构 → 构建（2026-10-19）
> 「Creatures, lives, they react to what's 刺激着它们, signal from outside, to hunt, to run, to live, or to build their own internal world. We sense, we 解构, we construct an organic being's sense. It's not just a visual tool, it's also connected to all my philosophy and projects. NPC, game design, movie languages…」

- 会动的东西 = 一个对刺激做反应的生物：**刺激 → 内部状态 → 行为**，不是按时间线摆。
- MV 的主角「不知道下一拍在哪」，只能对刺激反应；锚点是它的本能和命运。
- 落地：感官层（`src/sensorium.py`）把音乐拆成 心跳 / 威胁 / 饥饿 / 张力 / 节律；同一套以后给 NPC（输入换成游戏事件）。

## 4. 情绪是各媒介的公共坐标（2026-10-19）
> 「Music, architectures, gun movement, motion graphic, emotion, math… whether it's 莫扎特 or Nirvana style, they all connect and can transform to each other.」「Emotions link them.」

- 共享的结构：节律（振子）、张力 → 释放、冲击 → 衰减（后坐力 = 故障插针 = 鼓的包络）、对称与破缺、自相似。
- **莫扎特 = 往吸引子推；Nirvana = 顶在临界边缘（沙堆）**。不是不同维度，是同一系统的两种调法。
- ⚠️结构相通 ≠ 随便映射有意义。音量直接接亮度 = 千篇一律的可视化器。**值钱的是选择保留什么、丢掉什么** —— 那个翻译就是作品。
- 落地：一条「情绪轨」所有媒介都读（现场 rig、Eidolon 规则、以后的 NPC）。

## 5. 情绪不只是滤波器（2026-10-19）
> 「不同的 emotion 有不同的 patterns，不仅仅是滤波器而已。」「有不同乐器的时候，我们明显可以 demodulate。」

- 音源分离（Demucs）拆乐器；再往上：和声张力、重复与新颖、积累与预期（「something is coming」）、学出来的音乐表示。
- 落地：`tools/separate.py`（四轨）；`_TODO.md`「感官层升级」。

## 6. 语言是推理的节点（2026-10-19）
> 「Language is not just draft of thinking, it's 推理的节点, neural point of internal and outer mind flows.」

- 语言不是思考的草稿，是内外思维流交汇、转向的节点。Synapsis 用节点组织语言就是这个意思。
- 落地：需要 3D 而还没有的镜头，**先用文字卡占位**（语言本身就是画面锚点）。

## 7. 记忆让片子「实」（2026-10-19）
> 「剧本、分镜中的 elements 可以用 Hero 的 memory for story 来构建。This is real recall, and blink, and desire. Not just abstract motions.」「量级取决于影片风格，可以 90% abstract，也可以 90% real scene blend。」

- 规则 = 她现在的身体（怎么动）；具体物体 / 场景 = 她记得的东西（动的是什么、为了什么）。
- blink（1~3 帧闪回）/ recall（规则把实拍重建出来）/ desire（最优传输的目标）。
- 抽象 / 实拍比例 = 全片风格旋钮 `real_ratio`，可随时间变。

## 8. 克制：强度靠对比（2026-10-19）
> 「镜头插入太多了，需要更克制。鼓点时刻都在影响圆圈大小，这相当于媚俗 —— 过于强烈的情感平铺，反倒把其他的感情压下去了。」
> 同时：「原版很多地方太平、太 slow，我们可以有更多的 emotion inception，许多地方需要 uprise 和 stronger movement。」

- 两句不矛盾：**动态范围**。安静的地方真的安静，大动作留给锚点和段落交界；每拍都触发 = 平铺 = 媚俗。
> 「鼓点不要影响全局放大。This is too cheap. With no form in it.」
- **拍点要作用在有形的东西上**：某个元素、某个区块、某个结构（振子、裂缝、一块被标的区域），不是整幅画面一起放大 / 抖。全局放大没有「形」，只是音量的影子。
- 落地：`规则/剪辑规则.json` 的 `_克制` 说明和默认值；bump_beat 已关。

## 9. 分工与上下游（2026-10-16 / 10-17 / 10-19）
- Synapsis = 导演 / 编剧 / 构思；3_VisualProcess = 现场 live rig（像 The Glitch Mob 的 The Blade）；Eidolon = 后台。
- 上游定格式，下游现读、不存副本、不静默回退；下游不能反过来约束上游。
- 作品和软件分开（`Projekt_Visual/` vs 各仓库）。
- 画面审美：克制 ≠ 无聊，画面必须有情绪和故事；厌恶同质化、廉价好莱坞味。

## 10. 主导是人和 LLM，代码只是已经会的手艺（2026-10-19）
> 「不要写得太死。我发现让你 LLM / VLM 高度介入，明显是更有机的。代码仅仅是我们已经实现的技巧，而不要作为主导，主导还是你和我。因为无论是代码，还是情感感知系统，都是在不断地进行升级。」

- 规则表、感官层、剪辑脚本 = **工具箱和默认值**，不是导演。
- 每一轮：渲出来 → **我（VLM）真的去看**（接触表、抽帧、条带图）→ 用审美和哲学判断 → 逐镜头决定覆盖哪条规则、改哪个参数、哪里打破规则 → 再渲。用户看、给锚点、纠正。
- 规则自动跑出来的结果是「初稿」，不是答案；发现规则做不到的，就手动（写进作品的覆盖文件 / 锚点），而不是为了让规则通用而把规则写死。
- 代码和感官系统一直在升级：文档里记「现在会什么」，不记「永远该怎样」。

## 11. ⭐特效服务于叙事，不服务于自己（👤十年前和 Zaoeyo 的对话，2026-10-19 重提）
> 「We are motion graphic and VFX artists, but CGX or FX can not live alone. That is showing off, like Michael Bay. FX always serve the storytelling, the movie languages, the emotion. It tweaks your feeling.」「刚才第一版的某些地方电磁干扰就太频繁了。」

- 放在所有技法的最上面。先问「这一刻故事需要观众感觉到什么」，再问用什么效果、打在谁身上、多重 —— 答案也可以是「什么都不要」。
- 所以必须有 LLM / VLM 介入：看一段画面、推理它的情绪、判断效果是否在服务它。规则只回答「怎么动」。
- 鼓点打在谁身上，取决于它在表达什么：心跳 / 脚步 / 敲门 / 冲击 / 钟。同一首歌里鼓点的身份可以变，这个变化本身就是故事。

## 12. Thymos：先验、主旨、动机（2026-10-19）
> 「必须有一段先验价值，一段 guidance，background story。这段文字决定了这个视频的主旨，也表达了这个『生物』当前的情绪状态。It wants something. It has its motivation. Those image blinks can conclude to this creature.」

- 名字：**Thymos（θυμός）**—— 荷马史诗里胸中「想要」的那团东西（欲望、愤怒、勇气、冲动）。可配 **Telos（τέλος）**= 主旨 / 终点。
- 每部作品一份 `Projekt_Visual/<作品>/Thymos.md`，**用户写**，情绪锚点的源头。
- 用法：我每轮看画面前先读它，当判断的尺子；记忆 blink 从它长出来（它记得 / 怕 / 想要什么），反过来所有 blink 看完能拼出这个生物；它的状态可以决定鼓点的身份。

## 13. 信息带宽与分工：什么交给机器，什么交给人（2026-10-19）
> 「我们现在讨论的似乎是信息带宽和信息节奏，哪些交给 LLM 哪些交给人类……machine 处理序列快、大量文字快；人类拥有高带宽、多通道、多类型感知通道。情绪两者都可感知（LLM 推理），先验价值判断可以从人类那里获取，你也可以提建议。」

| | 人 | 机器（LLM / 代码） |
|---|---|---|
| 进来的带宽 | **极高**：同时看动作、听节奏、身体感觉，实时 | 低：我看的是抽样的静帧（接触表），**听不到声音**，动作和节奏要靠数字推 |
| 出去的带宽 | 低：打字慢、会累 | **极高**：一秒铺 76 段、7000 帧，逐帧对齐不出错 |
| 擅长 | 先验价值、品味、「这里不对」的直觉 | 序列、大量文字、一致性、记全、找重复、把一句话展开成全片 |
| 情绪 | 直接感到 | 推理出来（从画面、结构、文字） |

- **设计原则**：给人**密的媒介**（视频预览、海报、条带图），向人要**稀的决定**（锚点、一句话、「太媚俗」）；机器把稀的决定展开成密的结构。不要让人做机器快的事（对齐、列清单、改 76 行），也不要让机器假装做人强的事（替人判断节奏的手感）。
- 例子：用户两个切点 → 乐句格子 → 76 段 → 7000 帧；纯文字剪辑表（机器写满，人改几行）；20 秒出的无效果预览（人用高带宽去看）。
- 我的盲区要说出来：我看不到运动、听不到音乐，所以「节奏对不对、动得舒不舒服」归用户判断；「重复、一致性、有没有偏离 Thymos」我来盯，也可以主动提建议。

### §13 的对照与修正建议（来自「Synapsis 哲学」会话，2026-10-19；⚠️待用户逐条过，过了再并进正文）
- **对应**：Synapsis 四层 —— 设计层 = 人的稀决定（Thymos 是设计层的根）；参数层 = 机器；配置层 = 「机器写满、人改几行」（和纯文字剪辑表同构）；运行层 = 给人的密媒介。「回放比实时更重要」两边都服务：人的注意力在时间上是串行的，回放让人按自己的节奏看；机器离线分析整段。FK 的「主张 vs 观测」= 分歧点。
- **画布一半是稀界面**：「用密的方式显示、用稀的方式编辑」。⚠️**密媒介 ≠ 多文字**：大段文字对人是低带宽（`__synapsis/` 台账 AI 写满、用户几乎不看）；只有图、视频、条带图才是人的密媒介。
- **a. 带宽按通道分，不按人 / 机器分**：感知通道（像素、声音）人高机器低；符号 / 结构通道（数值流、日志、图结构）机器高人低。
- **b. 「两边一致更可信」要求独立**：如果机器的情绪判断是从用户写的 Thymos 推出来的，一致是必然，不算交叉验证（「两个 AI 说一样的话不是交叉验证」同理）。
- **c. 信息节奏**：稀决定在**写**的时候不被密信息打扰；密信息在**看**的时候才给（用户 10-08 否决画布上的「主张 / 观测不一致」⚠，理由是限制思维 —— 分歧要在人主动观测时才拿出来）。
- **d. 提议 vs 拍板**：LLM 可以提议改先验 / 意图，写进去要用户拍板（和 Synapsis「做不到意图就报差距，别改意图」一致）。
- **e. 思考不是劳动**：用户亲手写几千个节点不违背「别让人做机器快的事」—— 那是思考本身；思考草稿不能为省输出交给机器写，交出去就没思考了。§13 管的是**劳动**分工。
- **b 的补法（Synapsis 哲学会话建议，待用户过）**：每轮先**盲读** —— 不看 Thymos，只看画面，写一句情绪判断；再**贴读** —— 读 Thymos，写一句对照。盲读和用户感受一致，才算独立印证；盲读和 Thymos 对不上的地方 = 分歧点。不改流程，成本很低。

## 14. 格罗滕迪克：不只创作，还要建立体系（2026-10-20）
> 「看起来有人抢先了哟（@anabology）。但我们是格罗滕迪克，我们不仅创作，我们还要建立一个体系，right?」

- 格罗滕迪克的「涨潮」：不拿锤子去敲一颗硬核桃，而是让水慢慢涨上来，把它泡开 —— 建立足够一般的框架，具体问题自己就化开了。这和 §1（锚点 + 规则涌现）是同一个姿态。
- 别人做出一部好片子是一次；我们要的是**做出一部又一部片子的那套东西**：感官层、规则表、锚点、Thymos、剪辑表、现场 rig、后台。每一部片子同时是作品和体系的测试用例。
- 对照 @anabology《18 months to escape the permanent underclass》（接触表在 `Projekt_Visual/_参考库/anabology_接触表/`）：强在主题 / 叙事、角色一致、动态文字、UI 卡片当叙事道具；数字和图表是装饰性的讽刺，不是真的；画面是手工编排。我们的差异 = 符号说真话 + 规则涌现 + 一套可复用的体系。可以学：动态文字跟歌词、UI 卡片讲故事、「Look 01…」式的章节结构、角色一致性。

## 15. 质感来自于有审美的信息量（2026-10-23）
> 「质感来自于有审美的信息量。」——起点是香农：「信息来自于数据不可压缩的那一部分；概率越小的信息，交给越长的比特序列。」

- **两端都没有质感**：纯噪声不可压缩、信息量最大，但每个点各说各的，什么也没说成；纯装饰几乎可以压成一行，是空的。质感在中间 —— **有结构的信息**。
- **真实物体为什么有质感**：表面记录了历史（划痕、磨损、氧化），每一处都是一条真信息。和「符号说真话」（HUD 写真参数）是同一件事。
- **审美 = 可读的层级**：远看一个形，近看一层结构，贴近还有字和数；每走近一步都有奖励，任何距离都不乱。（对照：Schmidhuber「有趣 = 压缩进度」—— 观者每看一眼都能多压缩出一点规律。）
- **香农编码 → 画面权重**：越罕见的事件（自信息 −log p 越大）给越多的「码长」：更多帧、更大的字、更多空间；常见的拍点只给短标记。可以直接落地成规则：视觉权重 ∝ 事件的自信息（起音强度 / 节点被选中的概率在全曲分布里有多罕见）。
- ⚠️香农的信息量不等于意义：它度量的是「惊讶」，不是「重要」。意义由故事（Thymos）给，信息量负责让意义读得出、看不完。
- 👤总纲：**核心跟着 Thymos 和情绪流；数学是积木和审计视角，不是导演。** 往外走的探索（Kolmogorov / Gell-Mann / Schmidhuber / Meyer / Huron …）见 `笔记_信息、期待与情绪.md`（探索稿，不是判据）。

## 16. 情绪是心海上漂浮的一艘船（2026-10-23）
> 「情绪就是 a floating ship on the mind ocean。」「最终画面必然是要伴随整体元素或镜头始终在动的（即使很多时候很缓慢），attention 时刻在变。静态的可以作为分解效果展示、看效果用。」

- 成片里没有绝对静止：哪怕很慢，也有东西在漂；注意力（亮的标签、被拨的弦、焦点）时刻在换位置。
- 静态 / 锁机位的样片 = 效果测试（拆解展示），不是成片的状态。
- 和 §15 一起：信息量给质感，漂浮给生命。
