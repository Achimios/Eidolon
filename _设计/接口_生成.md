> 来源：火山方舟官方 API 参考（创建视频生成任务 / 图片生成 API，页面更新于 2026-10-20），Tripo 平台文档。

## Seedream 5.0 pro / flash（`/images/generations`）
| 能力 | 怎么用 | 限制 |
|---|---|---|
| **参考图**（图生图 / 多图融合） | `image`: 字符串或数组；**URL 或 base64**（`data:image/png;base64,...`）→ 本地图直接传 | pro / flash **最多 10 张**；单张 ≤30MB，总像素 ≤3600万 |
| 提示词里指代 | 「图1 的构图、图2 的光」 | 中文 ≤300 字 / 英文 ≤600 词，太长会丢细节 |
| 尺寸 | 档位 `1K` / `1.5K` / `2K`（比例写在 prompt 里），或 `宽x高` | 宽x高：总像素 [921600, 4624220]，比例 [1/16, 16]。21:9 可用 `2560x1096`。**1.5K 与 1K 同价、效果更好** |
| ⭐**图层拆分** | `layer_decomposition: true` + 单张图 | 底图 + 最多 16 个透明 PNG 图层，带 z_index / bounding_box → **直接拿来做 2.5D 视差**（Blender 里分层摆深度） |
| 透明背景 | `background: transparent`，只限图生图，输入一张带 alpha 的 png | 输出 png |
| 输出格式 | `output_format: png / jpeg` | |
| 返回链接 | 24 小时有效 → 立刻下载（ark.py 已经这样做） | |
| ⚠️组图 / stream / 联网搜索 | 只有 5.0 lite / 4.x 支持 | pro/flash 别传 `sequential_image_generation` |

## Seedance（`/contents/generations/tasks`，异步）
**三种模式互斥，不能混用：**① 首帧 ② 首尾帧 ③ 全模态参考（图 + 视频 + 音频）。
想在 ③ 里要首帧：在提示词里说「以图片1 为首帧」（不保证严格一致）。要严格一致就用 ①②。

| | 2.5 | 2.0 / fast |
|---|---|---|
| 时长 | 4–30 s，或 -1 智能 | 4–15 s，或 -1 |
| 参考图 | 1–30 张 | 1–9 张 |
| 参考视频 | ≤10 个，总 ≤30 s（单个 2–30 s） | ≤3 个，总 ≤15 s |
| 参考音频 | ≤10 段，总 ≤30 s；**可以只传音频** | ≤3 段，总 ≤15 s；不能只传音频 |
| 分辨率 | 480p / 720p / 1080p（1080p = 10bit HEVC） | 2.0：到 4k；fast：只到 720p |
| ratio | 16:9、4:3、1:1、3:4、9:16、**21:9**、adaptive；⚠️**首帧 / 首尾帧 / 编辑 / 延长只能 adaptive**（跟首帧图的比例走） | 都可指定 |
| ⭐样片模式 | `draft: true` → 480p 预览；满意后用 `{"type":"draft_task","draft_task":{"id":...}}` 生成正式版（复用构图运镜），7 天内有效 | 无 |
| 编辑 / 延长 | `omni_reference_task_type: edit / extend` + reference_video | 提示词里说 |
| 输出 | mp4，或 **mov（yuv444p，适合调色 / 抠像 / 合成）** | mp4 |
| 连续镜头 | `return_last_frame: true` → 尾帧 jpg → 当下一段的首帧 | 同 |
| 声音 | `generate_audio` 默认 **true** → 我们要关（音乐是原曲） | 同 |
| 插队 | `priority` 0–9 | 同 |

**素材怎么传：**
- 图片：URL / **base64** / `asset://` —— 本地图直接传。单张 <30MB，边长 300–6000 px，比例 0.4–2.5。
- 音频：URL / **base64** / asset —— wav、mp3，单段 ≤15MB。
- ⚠️**视频：只能 URL 或 asset://，不能 base64。** → Blender 镜头指导**视频**要传上去得有公网地址（方舟 Files API 能不能给 Seedance 用：【没验到】）。在那之前：用**首帧 / 首尾帧图片**做镜头指导（都是 base64 能传的）。
- 请求体 ≤64MB。
- ⚠️**不支持含真人人脸的参考图 / 视频。** 我们的全息女性、原片里 CG 角色应该没事；原片里有真人脸的帧会被拒。

**对我们的意义：**
1. 我们的「蓝色全息女性」角色一致性 → Seedance 2.5 最多 30 张参考图；Seedream 最多 10 张。先用 pro 定一组「她」的设定图（正面 / 侧面 / 碎裂态），之后每次生成都带上。
2. **2.5 能吃 30 秒音频** → 把那一段原曲（或 Demucs 的鼓轨）当 reference_audio，画面跟音乐走。
3. 样片模式（480p draft → 正式）比「2.0 fast 出草稿、2.5 重新出正式」更省：正式版直接继承草稿的构图。→ 建议改分工（等👤）。
4. 首尾帧 = 我们的锚点语法：首帧 = 这一段开始她的样子，尾帧 = 结束时。中间的变形交给模型。

## Tripo
- ⚠️**V2 API 2026-11-01 停用**（10 月 1 日起已不维护）→ 只用 **V3**（`https://openapi.tripo3d.ai/v3`）。
- 生成：text-to-model / image-to-model / **multiview-to-model**（正 / 左 / 后 / 右，正面必填，至少再给一张）。`texture: false` 出白模；`pbr: true` 出材质贴图。
- ⚠️要后续绑骨 / 改贴图就**别设朝向参数**（会转错）。
- 动画 = prerigcheck → rig → retarget。rig 类型：biped / quadruped / hexapod / octopod / avian / serpentine / aquatic。v2.5 骨架：27 个预设（idle walk run dive climb jump slash shoot hurt fall turn…）；v1.0：biped 101 个预设。retarget 一次最多 5 个动作。
- 绑骨前先做完所有网格编辑（分件 / 减面 / 转格式会丢骨骼）。
- 适合：人形、四肢清楚、衣服单层。⚠️上面的动画细节是 V2 文档，V3 的路径名拿到 key 后实测（【没验到】）。
