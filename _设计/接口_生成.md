# 接口：生成服务各自支持什么（2026-10-20 查官方文档）

> 来源：火山方舟官方 API 参考（创建视频生成任务 / 图片生成 API，页面更新于 2026-10-20），Tripo 平台文档。
> 文档会变：调用报 400 时先回来对这份，再去官网核对。【没验到】= 文档写了但我们还没实测。

## Seedream 5.0 pro / flash（`/images/generations`）
| 能力 | 怎么用 | 限制 |
|---|---|---|
| **参考图**（图生图 / 多图融合） | `image`: 字符串或数组；**URL 或 base64**（`data:image/png;base64,...`）→ 本地图直接传 | pro / flash **最多 10 张**；单张 ≤30MB，总像素 ≤3600万 |
| 提示词里指代 | 「图1 的构图、图2 的光」 | 中文 ≤300 字 / 英文 ≤600 词，太长会丢细节 |
| 尺寸 | 档位 `1K` / `1.5K` / `2K`（比例写在 prompt 里），或 `宽x高` | 宽x高：总像素 [921600, 4624220]，比例 [1/16, 16]。21:9 可用 `2560x1096`。**1.5K 与 1K 同价、效果更好** |
| ⭐**图层拆分** | `layer_decomposition: true` + 单张图 | 底图 + 最多 16 个透明 PNG 图层，带 z_index / bounding_box → **直接拿来做 2.5D 视差**（Blender 里分层摆深度） |
| 透明背景 | `background: transparent`，只限图生图，输入一张带 alpha 的 png | 输出 png |
| 输出格式 | `output_format: png / jpeg` | |
| 返回链接 | 24 小时有效 → 立刻下载（ark.py 已经这样做） | |
| ⚠️组图 / stream / 联网搜索 | 只有 5.0 lite / 4.x 支持 | pro/flash 别传 `sequential_image_generation` |

## Seedance（`/contents/generations/tasks`，异步）
**三种模式互斥，不能混用：**① 首帧 ② 首尾帧 ③ 全模态参考（图 + 视频 + 音频）。
想在 ③ 里要首帧：在提示词里说「以图片1 为首帧」（不保证严格一致）。要严格一致就用 ①②。

| | 2.5 | 2.0 / fast |
|---|---|---|
| 时长 | 4–30 s，或 -1 智能 | 4–15 s，或 -1 |
| 参考图 | 1–30 张 | 1–9 张 |
| 参考视频 | ≤10 个，总 ≤30 s（单个 2–30 s） | ≤3 个，总 ≤15 s |
| 参考音频 | ≤10 段，总 ≤30 s；**可以只传音频** | ≤3 段，总 ≤15 s；不能只传音频 |
| 分辨率 | 480p / 720p / 1080p（1080p = 10bit HEVC） | 2.0：到 4k；fast：只到 720p |
| ratio | 16:9、4:3、1:1、3:4、9:16、**21:9**、adaptive；⚠️**首帧 / 首尾帧 / 编辑 / 延长只能 adaptive**（跟首帧图的比例走） | 都可指定 |
| ⭐样片模式 | `draft: true` → 480p 预览；满意后用 `{"type":"draft_task","draft_task":{"id":...}}` 生成正式版（复用构图运镜），7 天内有效 | 无 |
| 编辑 / 延长 | `omni_reference_task_type: edit / extend` + reference_video | 提示词里说 |
| 输出 | mp4，或 **mov（yuv444p，适合调色 / 抠像 / 合成）** | mp4 |
| 连续镜头 | `return_last_frame: true` → 尾帧 jpg → 当下一段的首帧 | 同 |
| 声音 | `generate_audio` 默认 **true** → 我们要关（音乐是原曲） | 同 |
| 插队 | `priority` 0–9 | 同 |

**素材怎么传：**
- 图片：URL / **base64** / `asset://` —— 本地图直接传。单张 <30MB，边长 300–6000 px，比例 0.4–2.5。
- 音频：URL / **base64** / asset —— wav、mp3，单段 ≤15MB。
- ⚠️**视频：只能 URL 或 asset://，不能 base64。** → Blender 镜头指导**视频**要传上去得有公网地址。在那之前：用**首帧 / 首尾帧图片**做镜头指导（都是 base64 能传的）。⭐**本地渲染当运动参考怎么传 → 下面「本地视频当参考」一节（2026-10-21 实测）。**
- 请求体 ≤64MB。
- ⚠️**不支持含真人人脸的参考图 / 视频。** 我们的全息女性、原片里 CG 角色应该没事；原片里有真人脸的帧会被拒。

**对我们的意义：**
1. 我们的「蓝色全息女性」角色一致性 → Seedance 2.5 最多 30 张参考图；Seedream 最多 10 张。先用 pro 定一组「她」的设定图（正面 / 侧面 / 碎裂态），之后每次生成都带上。
2. **2.5 能吃 30 秒音频** → 把那一段原曲（或 Demucs 的鼓轨）当 reference_audio，画面跟音乐走。
3. 样片模式（480p draft → 正式）比「2.0 fast 出草稿、2.5 重新出正式」更省：正式版直接继承草稿的构图。→ 建议改分工（等👤）。
4. 首尾帧 = 我们的锚点语法：首帧 = 这一段开始她的样子，尾帧 = 结束时。中间的变形交给模型。

### ⭐本地视频当参考（2026-10-21 查文档 + 实测，账号现状下）
**结论：只用现在这把方舟 API Key，没有任何办法把本地 mp4 喂给 Seedance 当 reference_video。** 必须先有一个 Seedance 服务器能 GET 到的 https 地址。

实测（seedance 2.0 fast，建任务就被拒 = HTTP 400，不扣费）：
| 传法 | 结果 |
|---|---|
| `data:video/mp4;base64,...` | 400 `reference_video must be provided as a web url` |
| Files API 的 id（`file-2026...`）直接当 url | 400 `invalid url` |
| `file://file-...` | 400 `invalid url scheme` |
| `video_url: {file_id: ...}` | 400 `url field cannot be empty`（不认这个字段） |
| `type: input_video`（Responses API 的写法） | 400 只认 `text / image_url / audio_url / video_url / draft_task` |
| `asset://<随便什么>` | 400 `Your account has not activated the Asset Service`（→ 我们的账号**没开素材服务**） |

**Files API**（`POST /api/v3/files`，multipart，`purpose=user_data`）：✅ 用 API Key 就能传，实测 8.4 MB mp4 几秒变 `active`；`expire_at` 可设 1–30 天，默认 7 天；默认存储单文件 ≤512 MB。⚠️但它是给 **Responses / Chat API（视频理解）** 用的，返回里**没有下载 URL**，Seedance 不认 → 对出视频没用。存储费用：文档没写，【没验到】。

**素材库（asset://）为什么也不是出路：**
- 接口是火山 OpenAPI（`ark.cn-beijing.volcengineapi.com/?Action=CreateAssetGroup / CreateAsset&Version=2024-01-01`），**只认 AK/SK 签名**，不认方舟 API Key —— 我们 creds 里没有 AK/SK。
- `CreateAsset` 的素材**也只能传公网 URL**（不支持 base64 / 文件上传）→ 还是得先有 URL，绕不过去。
- 官方警告原文：素材资产应为**虚拟人像**，非虚拟人像类素材无需入库；`GroupType` 目前只有 `AIGC`（虚拟人像）。我们的 MEMS / 粒子渲染不是人像 → 用途不对口，审核会不会过：【没验到】。
- 门槛：首次建组前在控制台签**授权函**；走 API 要「高级创作权益（Entry）」及以上（Entry 免费，素材 / 组各 50 个，CreateAsset 3 QPM），开通要**企业实名认证** + 合规评测 + 手机校验。付费档 ¥1 万/月起。素材入库异步，视频处理更慢，`GetAsset` 轮询到 `Active` 才能用。

**真正可行的路：火山 TOS 私有桶 + 预签名 URL**（要👤在控制台开 TOS、建一个私有桶、给我一对 AK/SK —— 我没动）
- 文档原话只写「视频的公网 URL」，教程建议放 TOS 并设公共读。**私有桶的预签名 URL 能不能用：【没验到】**。旁证：素材库自己返回的素材 URL 就是 `*.tos-cn-beijing.volces.com/...?X-Tos-Signature=...` 这种预签名链接，说明方舟内部本来就这样取文件；预签名 URL 本质是带签名的普通 https GET，链接过期就失效，不算公开发布。
- 视频要求（官方）：mp4 / mov，H.264 / H.265，单个 ≤200 MB，24–60 fps，宽高 300–6000 px，比例 0.4–2.5，总像素 [407696, 8295044]；2.0 系列单个 2–15 s、最多 3 个总 ≤15 s；2.5 单个 2–30 s、最多 10 个总 ≤30 s。我们的 `09c_MEMS耳蜗_drop1.mp4`（1920×1080 / 24 fps / 3.58 s / 8.4 MB）全部合格。
- 顺带：带视频输入的 Seedance 2.0 计费更贵（第三方报道 46 vs 28 元 / 百万 token，【没验到】官方价目）。

## Tripo
- ⚠️**V2 API 2026-11-01 停用**（10 月 1 日起已不维护）→ 只用 **V3**（`https://openapi.tripo3d.ai/v3`）。
- 生成：text-to-model / image-to-model / **multiview-to-model**（正 / 左 / 后 / 右，正面必填，至少再给一张）。`texture: false` 出白模；`pbr: true` 出材质贴图。
- ⚠️要后续绑骨 / 改贴图就**别设朝向参数**（会转错）。
- 动画 = prerigcheck → rig → retarget。rig 类型：biped / quadruped / hexapod / octopod / avian / serpentine / aquatic。v2.5 骨架：27 个预设（idle walk run dive climb jump slash shoot hurt fall turn…）；v1.0：biped 101 个预设。retarget 一次最多 5 个动作。
- 绑骨前先做完所有网格编辑（分件 / 减面 / 转格式会丢骨骼）。
- 适合：人形、四肢清楚、衣服单层。
- ⭐**V3 详细能力表 + 推荐预设 + 实测结果 → [`接口_Tripo.md`](接口_Tripo.md)**（2026-10-20；上面几条以那份为准）。客户端 `src/tripo.py`。
