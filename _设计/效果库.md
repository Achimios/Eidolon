## 遮罩算不算「不够数学」？
- 遮罩是**形状的锚点**（她的轮廓，来自生成图 + BiRefNet 抠像）——这是低熵注入，正当。
- 不够数学的是**遮罩里面怎么动**：如果位移是随机噪声 / 手 K，就是人工；如果是**歌曲波形按扫描线写进去**、**起音决定哪一行断**，就是信号在说话。→ The Crew 的地图碎裂可以学，但把它的「随机横移」换成真信号（见 17_scan_tear）。

## 2D 算 → 3D 软件渲（克拉尼、碎裂这类）
- 👤问：克拉尼应用到 3D 元素上，直接 Blender / C4D 还是先 Python？→ **先 Python 算粒子**（驱动来自感官层，一个真源），要 3D 场景时导出点缓存给 Blender 只渲染。
- 真源只有一个：**Python 按感官层算出每帧的点**（谁动、怎么动）。
- 要进 3D 场景（灯光、景深、和 Tripo 模型互动）：导出逐帧点缓存（.ply 序列 / numpy → Blender 几何节点读入实例化），**Blender 只负责渲染**，不重新实现动力学（一个镜头只认一个真源）。C4D 同理。
- 要叠在实拍 / Seedance 画面上：2D 渲出 + 遮罩 / 深度合成；美化（光晕、调色）交给 Zaoeyo。
