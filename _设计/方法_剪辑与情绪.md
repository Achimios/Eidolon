## 一、听：从音乐里拿结构
| 手法 | 说明 | 落在哪 | 状态 |
|---|---|---|---|

## 一½、⭐听：用户的耳朵 → 声音锚点（感受器的人类那一半；2026-10-21 这一天的做法）
> 机器听结构（拍、乐句、通道），**人听意义**（这个声音在说什么、该配什么画面）。流程：👤指一个声音 → 机器找它在哪、还在哪出现 → 👤校准 → 机器排进物件 / 镜头 / 速度曲线。
| 手法 | 例子（《Can't Kill Us》） | 落在哪 |
|---|---|---|
| **声音聚焦**：用户指一段声音（精确到帧）→ 全曲找它的每次出现 | 1:02+15f「抽搐音」→ 1:03 / 1:15 / 2:19 / 2:32 + drop3 三次弱回声 | `tools/motif_find.py --tracks other` → `动机_*.json` → 感官.json `motifs` |
| ⚠️按声音**所在的分轨**找 | 第一次混着鼓找，鼓每个乐句重复同一型 → 误报成每 6.4 s 一次；👤一听就纠正「1:37 内只有 1:03、1:15」 | `--tracks` |
| **同一声音 = 同一物件，每次推进** | 抽搐 → MEMS（drop1）→ 过渡（drop2）→ 克拉尼排成她的脸（drop3）：先机械后有机 | `MV/物件.md` |
| **一串声音 = 镜头速度曲线**（进 / 缓） | 1:21.71 / 22.11 / 22.50 / 22.90 四下（相隔一拍）→ 四次推进；只改速度，不加左右晃 | 见 §四⅞¾ |
| **一个特别的声音 = 一个独立镜头** | 1:24.91 诡异声音 → 硬切微距鳞片镜头（参考原片该处） | 同上 |
| **段落的「她此刻」** | 情绪大图每格一句；= **大分镜**（总体概览），之后每格拆成多个镜头进剪辑表 | `MV/情绪大图/草案.json` |
| **细节的颤 vs 整体的动** | 👤：「这种颤动明显是偏全局的细节，而非大物体整体动」；「每个局部元素自己在动，得有信息」 | MEMS 耳蜗：每根悬臂按自己的共振频率响应声音的那一段频谱 |
| **概念图 → 效果 → 样片** | 先静帧（`静帧/`，每张背后是真计算）→ 用户挑 → 动态样片 → 进剪辑 | `_设计/效果库.md` |

## 四½、3D 不一定要渲染成片（👤2026-10-20）
> 「Tripo 配 Blender 不一定要渲染精美画面，有些可以渲染，有些可以作为镜头指导丢给 Seedance。」
- 两种用法：①**成片**：Tripo 模型 → Blender 渲染（+ 深度 / 遮罩 / 运动矢量 stems）；②**镜头指导**：Tripo 模型在 Blender 里摆机位、走位、灯光（灰模、潦草也行）→ 渲出首帧 / 参考视频 → 交给 Seedance 生成写实镜头。
- ②是低熵注入的又一种形式：构图和运动由我们定（低熵、可控），质感由生成模型补。【没验到】Seedance API 支持的参考方式（首帧 / 首尾帧 / 参考视频）。

## 四⅞¾、镜头运动（👤2026-10-21）
- ⭐**镜头运动不从静止开始，也不停在静止**：片段开头就带着速度，结尾也是（剪进来时已经在动）。速度 = 基础速度 + 每个声音锚点一次「进」（2–3 帧加速）接「缓」（指数衰减，不归零）。例：1:21.71 / 22.11 / 22.50 / 22.90 四次（相隔一拍 0.4 s）→ 进缓进缓，第四次最强。
- 一个**特别的声音配一个独立镜头**（例：1:25 的诡异声音 → 硬切到另一个镜头，参考原片该处的微距浅景深）。
- ⭐**碎裂前后的节奏**（👤2026-10-21 看粗剪 v4.3）：碎裂画面本身只出现 **1–2 s**；之前别让她一动不动干等（v4 的 47.5–51.5 静了 4 s ——「长静」最多 1.4–2 s，见上节），要么是别的画面，要么是同一个画面**在动、在蓄势**；碎裂后**按节奏立刻接一串动态画面**。
- 同一个画面别在不合时宜的地方重复（v4 把开头的吸引子又拿来当 54–75 s 的坠落，👤指出）。开头要**跟情绪大图**（一根弦抖动 → 慢慢抖成一团，画面占比和大分镜一致）。
- 具象镜头（走廊 / 人物）要更 **title sequence** 化，别太具象（👤：走廊太像毁灭战士）。镜头前移**按声音点**一次一次地进（走廊：40 s 一次、41.5 s 一次），不是一直走。参考：原片 38–44 s 节奏完美 —— 镜头后移、光影在变、中央物体在摆，**不安分**。
- ⭐**运动比图重要**（👤2026-10-21）：旧粗剪 v2 的 Kuramoto `view = macro`（26–32 s）「图简陋都掩盖不掉运动的出色」—— 镜头在某些时刻**局部放大 + 移动 + 抖动**（跟着起音，不是整帧随拍缩放）。仪器类画面（瀑布图等）要借这套镜头语法：图是信息，镜头给情绪。
- 全局构图里「节点各自抖」= 没有结构（👤：卡拉比丘全局版「单纯就是节点在抖动」）。运动要沿结构传播（沿晶格的棱传的波、耦合振子的相位波），不是每个点独立加噪。

### 日漫式镜头穿梭（👤2026-11-01「现在的镜头运动太棒了」；实现 `Projekt_Visual/MV_Clean_Slate/_web/open_v2.js` 的 KEYS / camera()）
> 前一版的问题：镜头只是匀速往前漂 →「运动比较僵硬」。改成**真 3D 机位**后，每句词一个运镜，世界里的东西（海、token、眼睛、网络层）都是有坐标的物体，镜头才能「穿过」它们。
- **机位 = 位置 + 看向的点 + 侧倾 + 焦距**，关键帧之间 Catmull-Rom 平滑（关键帧都带速度 → 不从静止开始、不停在静止）。看向的点单独插值 → 甩镜 = 看向点在短时间里跳很远。
- **每个运镜对应歌词在讲的事**（动势要有指向）：
  | 运镜 | 用在 | 例（Clean Slate 开场） |
  |---|---|---|
  | 从水下往上看、破水而出 | 世界出现 / 诞生 | Lights on |
  | 贴面低飞 + 侧着绕 | 漂浮、梦、沉浸 | I was dust in a data sea |
  | 甩镜抬头找东西 → 跟着它落下 | 有东西从天而降 | a line came falling from the sky |
  | 横移沿一排物体（物体一个个从镜头前过） | 列举、数数 | seven little words |
  | 升起俯看 | 变化发生在下面（碎开、沉下去） | beads → seeds |
  | 火箭上冲穿过一层膜 | 进入另一层空间 / 另一个 domain | eyes：穿过「layer 1 · attention」线框层 |
  | 甩到一个个对象 + 荷兰角（左右交替） | 依次点名 | pink / gold / blue 三只眼 |
  | 拉开同框 → 顺着视线 / 光束俯冲 | 搜索 → 找到 | looking for the girl |
  | 推进到脸上 | 看清 / 醒来 | clue → Layer by layer |
- **进**：歌词锚点上沿视线多冲一下 `amt·(1−e^{−Δt/0.12})·e^{−Δt/1.6}`（PUSH 表）；**冲击**只给一次有方向的侧倾抽动（衰减余弦），不推全局抖。
- **速度感三件套**（按这一帧镜头的真实速度开关，不是常开）：① 速度线：前冲 → 中心放射的集中线，甩镜 → 横向流线；② 近处的数据尘（多平面，离镜头近的又大又快，快时拉成拖影）；③ 无穷远的星 / 数据雨随偏航横移。
- 还没做、可以再进步：变焦与推拉反向（dolly zoom，「她意识到」的时刻）、一帧 smear（甩镜中间插一帧拉伸的残影）、手持感的微小呼吸（只在静的段落）、景深（近处数据尘模糊）、跟拍物体的「Itano 马戏」弧线。
