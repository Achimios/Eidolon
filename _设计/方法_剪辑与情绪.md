## 一、听：从音乐里拿结构
| 手法 | 说明 | 落在哪 | 状态 |
|---|---|---|---|
| 感官五通道 | 心跳（<120Hz）/ 威胁（起音冲击，180ms 衰减）/ 饥饿（慢响度反面）/ 张力（频谱质心）/ 节律（拍相位） | `src/sensorium.py`、`tools/sense_song.py` → `感官.json` | ✅ 自检 6 项 |
| 起音要用短窗 | 1024 点长窗会让起音整体早 ~30 ms；起音用 256 点短窗，时间取窗口中心 | 同上 | ✅ 误差 ≤ 6 ms |
| 归一化避开静音 | 片尾全静会把响度范围撑大、整首压平；只在「有音乐」的部分里定范围 | 同上 | ✅ |
| 起音强度取 ±3 帧最大 | 按帧直接取威胁值会落在冲击之前 | `tools/animatic_v2.py: onset_strength` | 🟡 待进感官.json |
| **用户锚点 → 乐句格子** | 用户两个切点吸附到起音，间隔 = 4 小节；格子铺满全曲，和段落对上 | `锚点.json` rules.phrase_grid | 🟡 手推；待自动检测 |
| 音源分离 | Demucs htdemucs 四轨；发现人声只在 breakdown 之后出现 | `tools/separate.py` → `分轨/` | ✅ 每轨通道待做 |
| 交叉校验 | 找「必须相等」的量：四轨相加 ≈ 原混音（残差 3.2%）；饥饿峰 = 手拆的两次吸气 | 各脚本打印 | ✅ |

## 二½、⭐纯文字剪辑表 + 快速预览（👤：「最快的方法其实是纯文字」）
- `Projekt_Visual/<作品>/剪辑表.txt`：一行一段（开始 / 素材 / 速度 / 备注），用户直接改，或在对话里说「第 N 段换成……」。
- `tools/edl.py preview`：不叠效果，480p，**按绝对帧号切**（按秒四舍五入会让全曲漂近 1 秒），整首约 20 秒出。先用它定节奏和感觉，满意了再出带效果的。
- 素材写法：`原片@m:ss` / `第二章:shot5@3.2` / `样片:文件@秒` / `图:路径` / `文字:……`（还没有画面的 desire 先用文字）/ `黑`。
- 以后 Synapsis 剪辑条、Visual 现场 rig 都读这张表；界面后做。
