# 理念：示波器、处理器、生长（2026-10-26，👤讨论）

> 起点：👤「也许我们应该先合成自己的音乐」+ Revision / Deadline 的示波器音乐《Triple Hit》。
> 这份是**理念与词汇**，不是实现。实现另起工具时回来对照。

## 一、底线（👤原话的意思）
- ⭐**要到 The Glitch Mob 的水平，就不能只是炫技**：必须有情绪、人声、素材、旋律。处理器只是调料。
- ⭐**每个处理器出场都要回答「这一刻她怎么了」**，答不出就不用。（Thymos 和情绪流是导演，数学是积木和审计，见 `哲学.md` §15）
- ⭐**Nirvana 胜过 Mozart**：先有 riff，循环、叠层、失真、即兴，作品从「玩」里长出来。作曲器要做成一件**能玩的乐器**，不是一台打谱机。
- 图案和音频的耦合度太低就没意思；高耦合（声音即画面）只在某些地方用。

## 二、架构：信号 → 处理器 → 目标，中间是调制矩阵
| 层 | 有什么 |
|---|---|
| **信号源** | 音频 / 分轨 / 乐谱事件（作曲器直接给，帧级真值）/ 图形 / CG / 实拍 / 👤写在轨道上的情绪描述 |
| **处理器** | 下面第三节整张表；示波器只是其中之一 |
| **目标** | 像素、运动（相机 / 物体）、规则（生长的参数、溶解的进度、剪辑的密度） |
| **调制矩阵** | 任一信号 × 任一目标，每条连线有自己的强度（mod matrix，同 VCV Rack / TouchDesigner 的思路）。不同层的处理强度、应用强度可以不同 |

**驱动方向**（三种都行，可以混用）：
- **声音驱动**（FK）：先有声音，画面是结果。
- **画面驱动**（IK）：先定形状，反推出声音。示波器音乐就是这种。
- **节奏驱动**：一份乐谱同时发给声音和画面（mg-styles-15 的 `cues.json` 就是这种）。

**半解耦**：形状交给音色和泛音；大小、亮度交给响度；旋转、变形交给音高或 LFO。乱的声音不一定要画出来，可以只当控制信号，去驱动实拍 / CG 的处理参数。

**扫描方式**是一个参数：XY 矢量 / 中心扩散 / 行扫 / 场扫 / 螺旋 / 自定义路径。

## 三、处理器家族
| 家族 | 处理器 | 画面 | 反过来（画面 → 声音） |
|---|---|---|---|
| 时域 | **李萨如 / XY** | 左声道 = x，右声道 = y，声音画出图形 | ✅ 示波器音乐 |
| | 测角仪（M/S 旋 45°） | 立体声宽度变成一团云 | |
| | 极坐标波形 | 波形卷成年轮 | |
| | ⭐**延迟嵌入** (x(t), x(t+τ)) | 任何声音都有一个「吸引子」：稳的声音是闭环，乱的声音是乱结构 | |
| 频域 / 时频 | 瀑布图 / 频谱图（做过） | 地形 | ✅ **频谱绘画**（逆 STFT；Aphex Twin 的脸、Doom 2016 Mick Gordon 塞进频谱的五芒星和 666） |
| | 色度图（12 音级） | 音高 → 色轮位置 | |
| | 小波图 | 低音粗、高音细，比瀑布图更有机 | |
| 结构 | ⭐**递归图**（自相似矩阵） | 整首歌的结构变成一张图：重复段 = 对角线，副歌 = 方块。信息量高、好看 | |
| 和声 | Tonnetz（音网格） | 和弦 = 三角形在格子上移动，转调 = 整体漂移 | |
| 物理 | 克拉尼（做过）、弦 / 膜振型、法拉第波、磁流体 | 声音让物质排列 | |
| 已有的 | 最优传输、信息图、瀑布图、音轨分解、像素溶解、现实瓦解 | 见 `效果库.md` | |

**两种把画面塞进声音的路**：李萨如在**时域**用形状做音色（形状 = 泛音，基本不改音高）；频谱绘画在**频域**占一小段时间和频带（听起来是一阵噪声扫频，叠在音乐上，不改旋律）。两条都是「画面高度解耦于旋律」。

## 四、示波器的物理（做模拟器时要满足）
- **点数预算**：一个图形每秒重画 f 次，听到的就是音高 f，每画一遍只有 `采样率 / f` 个点。**音越低，图形越精细；音越高，图形越简陋**，这是唯一的硬耦合。所以 BEC 用 **192 kHz**（每帧 60 fps 有 3200 个点）。
- **亮度 ∝ 1 / 光束速度**：慢的地方亮，快跳的地方几乎看不见，两声道下的「熄灭」就是靠极快地跳过去。
- **荧光余辉**：指数衰减（每帧乘衰减系数），加辉光模糊、加拖影，才看得出连续流畅的动画。
- ✅**交叉校验（2026-10-26 实测）**：`Triple Hit Final.flac`（192 kHz）画出的 XY 和原视频（扭结、圆环、碎片）一致，所以**只用了左右两声道**。B 站版（AAC 109 kbps）对不上：有损编码合并编码立体声，毁了相位。⚠️示波器音频一律用无损。
- 缺的：原视频里快跳留下的暗线和噪声云，在我粗糙的亮度权重下消失了 → 模拟器要按真实的余辉 + 辉光去做，再用它对照。

## 五、生长算法（及接先验的接口）
| 算法 | 长成什么 | 先验从哪接进来 |
|---|---|---|
| **空间殖民** | 树、叶脉 | 吸引点撒在她的轮廓上 → 她被长出来 |
| **DLA** | 珊瑚、闪电、冰花 | 偏置场（例：人声音高让它往上长） |
| **反应扩散（Gray-Scott）** | 斑、纹、迷宫 | 喂料率 / 杀灭率按图像亮度逐像素变化 |
| **差分生长** | 褶皱的曲线（脑回、珊瑚边） | 生长速率按场变化 |
| **Physarum（黏菌）** | 网络 | 痕迹图预先铺一张参考图 / 深度图 |
| L 系统 | 植物 | 语法规则 |
| 拉普拉斯生长、叶序、元胞自动机 | 雷击、螺旋、规则图案 | —— |
⭐**有机生长必须和其它先验交互**：结构由算法自己长出来，往哪长由先验决定。

### ⭐FIR / IIR 生长（👤的想法）
- **FIR 生长**：只看最近 N 个事件，记忆有限。结构跟着当下的声音变，过一会儿就忘（涟漪）。
- **IIR 生长**：有反馈，状态一直累积，会记住过去、会共振。**极点位置 = 记忆的长短**：
  - 极点在单位圆以内：回声慢慢消散，伤痕会愈合；
  - 贴近 1：伤痕永久留下；
  - 超过 1：失稳、炸开。
- 对上 Thymos：吸收残响 = IIR 累积；过载 = 极点越过 1；重组 = 把极点拉回圆内。**极点位置本身就是一条情绪曲线。**

## 六、感受器在自作曲时是真值
- 作曲器发出的每个音（帧、音高、起音、尾巴）直接写成事件，感受器不用猜，可以到帧级。
- 片段级的音高、拖尾、起落、情绪描述写在 Synapsis 的轨道上：作曲器写事件轨，👤写情绪轨。
- 外来的歌（如 Billie）才需要代码感受器 + LLM 感受器去猜。

## 八、音色从哪来
示波器音乐的形状就是音色，所以往往刺耳。两条路：a 形状只在少数「显影」时刻用，平时用正常合成器声音；b 把形状设计得本身就悦耳（低泛音、圆润曲线）。**建议 a 为主，b 点缀**（👤：仅在某些地方使用）。
