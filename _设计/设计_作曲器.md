## 〇、三条底线（👤）
1. **Nirvana 胜过 Mozart**：先有 riff，循环、叠层、失真、即兴，作品从「玩」里长出来。→ 作曲器是**一件能玩的乐器**，不是打谱机。
2. **要到 The Glitch Mob 的水平，不能只是炫技**：必须有情绪、人声、素材、旋律。示波器 / 处理器只是调料。
3. **作曲器发出的每个音都是真值**：直接写成事件轨，感受器不用猜（帧级）。

## 一、它是什么
一句话：**几条循环的层 + 一排旋钮 + 一个录像机**。你一边听一边拧，拧过的每一下都被记下来，最后出一首歌，同时出它的全部真值。

| 部件 | 是什么 | 对应的词（见词表） |
|---|---|---|
| 层（layer） | 一条循环：一个音色 + 一排格子（音序器）或一段采样 / 分轨切片。鼓、贝斯、pad、主旋律、人声切片、显影层各一条 | 振荡器、波形、音序器、琶音器 |
| 场景（scene） | 一组「哪些层在响、各自弹哪个 pattern」。段落 = 场景的切换（Ableton 的 Session 视图那种） | —— |
| 旋钮（macro） | 一个旋钮同时推好几个参数（例：「脏」= 失真增益 + 截止 + 混响湿度）。旋钮动作随时间记成曲线 | 调制、LFO、滤波、失真、侧链 |
| 录像机（take） | 一次「从头弹到尾」的记录：场景切换的时刻 + 每个旋钮的曲线 + 即兴插入的音。一首歌 = 一个 take | —— |
| 显影（reveal） | 少数时刻，某一层的声音换成**画形状的声音**（示波器音乐），画面上直接显出那个形状 | 李萨如、延迟嵌入 |

**为什么这样分**：「玩」的单位是层和旋钮（快、可以乱拧）；「歌」的单位是场景和 take（结构）。两者分开，乱拧不会毁掉结构，结构也不会把人锁死。

## 二、输出（每次渲染都出这三样）
1. **音频**：立体声混音 wav（无损，48 kHz / 24 bit；显影层单独 96 kHz 以上）+ **每层一条分轨**（自己合成的不用 Demucs 去猜）。
2. **事件轨 `作曲.json`（真值）**：
   ```json
   {
    "bpm": 120, "grid": {"anchor": 0.0, "beats_per_bar": 4},
    "notes":   [{"t": 秒, "dur": 秒, "pitch": midi, "vel": 0~1, "layer": "bass"}, ...],
    "hits":    [{"t": 秒, "layer": "kick", "vel": 0~1}, ...],
    "scenes":  [{"t": 秒, "name": "drop1", "layers": ["kick", "bass", ...]}, ...],
    "macros":  {"dirty": {"fps": 60, "v": [0~1, 每帧一个]}, ...},
    "reveals": [{"t0": 秒, "t1": 秒, "layer": "scope", "shape": "circle→outline:her"}, ...],
    "mood":    [{"t": 秒, "text": "👤写的一句她此刻"}, ...]
   }
   ```
   ⚠️**不合并成副本**：`作曲.json` 单独成文件，下游（edl、画面规则）直接读它（规矩：下游现读上游、不存副本）。`sense_song.py` 每次会整份重写 `感官.json`，所以合并进去会被冲掉。做法：`sense_song.py` 运行时如果作品文件夹里有 `作曲.json`，就用它的真值替换 `events.beats / downbeats / phrases`、写 `"beat_source": "composer:truth"`，并加一个指针字段 `"composer": "作曲.json"`；`channels`（心跳 / 威胁 / 饥饿 / 张力 / 节律）仍从分轨算。字段只增不改名。
3. **XY 显影层（可选）**：`reveals` 时段那一层的立体声 wav（96 kHz 以上的原件），交给 `tools/scope_sim.py` 出画面（已验证：和 Triple Hit 原视频相关 0.89–0.98）。混音里用的是重采样到 48 kHz 的版本；示波器读高采样率原件（点数预算 = 采样率 / 音高）。

**母带目标（写死）**：−14 LUFS 整体响度，真峰值 ≤ −1 dBTP（借 mgaudio 的响度校验 + pyloudnorm）。每次出片自动报这两个数。

**事件轨怎么驱动画面**：就是理念 §二的调制矩阵：任一事件 / 曲线 × 任一画面目标 × 强度。例：`macros.dirty` → 画面颗粒和撕裂强度；`notes[layer=bass]` → 某个有形物体的位移（不是全局放大，👤：「鼓点不推全局放大」）；`scenes` → 剪辑点（锚在场景上，不锚在秒数上，学 pdoom-video 的 `cut('歌词')`）。

## 二½、情绪入口：一条张力曲线当所有旋钮的总父级
第〇节说情绪流是导演，所以作曲器里要有一条**情绪曲线**，不是只有一条文字轨：
- 👤画或口述（「这里憋住」「这里炸」），我把它变成 0–1 的曲线，写进 `作曲.json` 的 `tension`；Thymos 的段落（吸收 → 过载 → 重组）就是它的骨架。
- 它是**所有旋钮的父级**：密度（多少层在响、格子多满）、脏度（失真 / 截止）、空间（混响湿度）、显影允许不允许出现，都按它的值限在一个范围里，旋钮只在范围里拧。
- **余响 = IIR 极点**（理念 §五）：延迟 / 混响的反馈 g 直接挂在情绪上。吸收段 g 往 1 推（声音记得越来越久，层越叠越厚）；过载 = g 越过 1 的那一下（反馈失稳、炸开，限幅器接住）；重组 = 把 g 拉回圆内（余响收短、干净）。**极点位置本身就是一条情绪曲线**，听得见也看得见（示波器上的拖尾长度）。
- 画面读同一条曲线（调制矩阵的源之一），所以声音和画面的「她此刻」是同一个数。

## 三、声音从哪来（三类，平时 + 显影）
| 来源 | 用在哪 | 现状 |
|---|---|---|
| **自己合成**（`synthkit`；mg-styles-15 的 `mgaudio` 可以借：PolyBLEP、梯形滤波、FM、Karplus-Strong、鼓、母带、响度校验，MIT） | 鼓、贝斯、pad、琶音、音效 | synthkit 有（词表 15 例）；mgaudio 的依赖已装（numba、pedalboard 0.9.25、pyloudnorm 0.2.0），**还没跑过** |
| **采样 / 分轨**：CC0 乐器采样（mgaudio 自带 VCSL，56 MB）、Can't Kill Us 四轨、Suno 出的歌 | 旋律、人声、质感 | 采样在 `_外部仓库/mg-styles-15/lib/audio/samples` |
| **人声**：Suno（👤网页端，唱歌）、Cortana TTS（念白，有 `fx` 和 `pos` 空间定位） | 「要有人声」的那条底线 | TTS 能用；Suno 等 👤 |
| **显影**：形状 → 声音（形状即音色） | 少数时刻（👤：「仅在某些地方使用」） | scope_sim 能画；「形状 → 音频」的生成器还没写（见第五节） |

## 四、怎么「玩」：交互形态（建议分三步走）
| 阶段 | 形态 | 能做到 | 要什么 |
|---|---|---|---|
| **A 先做** | **挑和叠（不是写）**：后台**一直循环播放**当前 8 小节，改动热重载（不停下来）；每次改动我渲出 **3–4 个变体**（换随机种子 / 微调 pattern / 旋钮走向不同），👤用耳朵挑一个、说「叠上去」或「换掉」；层、场景、旋钮写在一个 `歌.py`（或 yaml）里，但那是我的事 | 循环、叠层、挑、换；耳朵在环里 | 循环播放要一个音频输出包（`sounddevice`，👤已允许下载）；渲 8 小节的时间【没验到】，目标 < 3 秒 |
| B | **实时乐器**：Python 音频回调 + MIDI 控制器（👤拧真旋钮），录 take | 真的即兴：拧旋钮、按键插音，延迟 < 20 ms | `sounddevice`、`mido` 两个包；一个 MIDI 控制器（开放问题） |
| C | **网页面板**：浏览器里的旋钮 + 波形 + 内嵌示波器（WebAudio），导出 `作曲.json` | 不碰代码也能玩；可以给别人玩 | 前端工作量大；音频引擎要两份（Python 离线 + JS 实时）或只做控制面板 |

**建议**：A 立刻能开工，也最贴「Leo 的耳朵 + 我的手」这个分工（哲学 §13：人给稀疏的决定，机器展开成密的结构）。B 等 A 证明这套层 / 场景 / 旋钮的模型好用再做。C 先不做。
⚠️**A 和底线 1 的张力**：写谱、改谱本来偏 Mozart。所以 A 里 👤不写，只做两件事：**挑**（从变体里选，同 Seedream 的教训「从一堆里挑」）和**叠**（循环不停，层一条条加上去或拿掉）。Nirvana 的「玩」在 A 阶段就是挑和叠；真正动手拧是 B。

## 四½、输入方式：没有 MIDI 键盘、不会钢琴（👤2026-10-26 定：做成 HTML，另开会话「HTML composer」做）
> 👤：「我没有 MIDI 键盘，而且我从来不会钢琴。电脑键盘可以吗？不过没有力度，只有延时可以控制。大多数都交给后期调整吧？做成 HTML？」

**分工**：浏览器页面负责**玩和录**（延迟低、不用装东西）；最终的声音由 Python（`src/synthkit.py`，以后加 mgaudio）读同一份事件轨渲染。页面里的声音是预览，事件轨是真值。

| 输入 | 做法 | 录下什么 |
|---|---|---|
| **锁调电脑键盘** | 两排字母键 = 当前调式的音阶（默认 E 小调，可换），上排高八度；不会弹错音，👤只管节奏和走向。数字键选层 / 场景 | 每个音的按下 / 松开时间（毫秒级）、音高、层 |
| 力度（键盘没有） | 默认等力度；可选：按住时长 → 力度、Shift = 重音；其余后期在事件轨上画 | `vel` |
| **哼唱 / 唱** | 麦克风 → 浏览器里实时音高（YIN / 自相关），可选吸附到调式；同时把原始录音存成 wav（Python 这边可以再用 crepe 重算） | 音符 + 原始人声 wav（「要有人声、旋律」那条底线的一条路） |
| **拍** | 只拍节奏（空格 / 任意键），音高由和弦自动填 | 起音时间 |
| **XY 推子** | 鼠标 / 触控板在一块区域里拖 = 两个旋钮（如 x = 截止、y = 脏度）；还有情绪曲线 `tension` 也可以这样画 | `macros` 曲线（逐帧） |
| **挑** | 每次改动出 3–4 个变体，循环不停，👤听着挑 | 选了哪个（`picks`，可追溯） |

**循环**：页面一直循环 N 小节（默认 4 或 8），录音是叠录（overdub），可以撤销 / 静音 / 删层。可以把已有分轨（如《Can't Kill Us》四轨）拖进来当伴奏层，在上面玩。
**时间线**：同一个页面里一条时间线看全部层（音符块 + 曲线），拖动、删除、复制一段 = 剪辑音轨。
**输出**：`作曲.json`（格式见第二节，加 `input` 字段记来源：keyboard / hum / tap / xy / pick）+ 哼唱的 wav；存到作品文件夹，Python 这边 `render` 出无损混音 + 分轨 + 显影层。
**不做**：MIDI 设备（以后有控制器再加）、在浏览器里做最终音质。

## 五、osci-render 要不要当乐器
- 是什么：James H Ball，**GPL-3.0**，独立程序 / VST3 / AU；obj、svg、文本、Blender 场景、Lua 脚本 → 示波器音频；有 MIDI 和 DAW 自动化。README 没提命令行 / 无界面 / OSC（【没验到】，只读了 README）。
- 用法上：它是**给手玩的**（界面 + 插件），不适合被我们的脚本批量驱动。
- 许可上：当独立程序用、只拿它导出的音频，没问题；**不能抄它的代码进我们的仓库**（GPL 会传染到整个工具链）。
- **建议**：① 👤想手玩「显影」时，在 DAW 或独立版里用它，导出无损 wav 给我们（scope_sim 出画面、事件轨照记）；② 我们自己写一个很小的「形状 → 音频」生成器（路径 → 按周期 f 重采样成 L/R；f 决定音高，点数预算 = 采样率 / f，见理念 §四），MIT，脚本可驱动，放进作曲器当一种层。两条不冲突。

## 六½、「好听」写进流程（最大的风险，不能只写在风险格里）
1. 👤给 2–3 首参考曲 = 声音的锚点（和画面一样先要锚点）。
2. **A/B 对照**：我们的片段和参考曲统一到同一 LUFS 后切换着听；附一张频谱平衡对比图（低 < 250 Hz / 中 250 Hz–4 kHz / 高 > 4 kHz 三段能量 + 整体频谱曲线叠在一起）。
3. 机器能查的先查（响度、真峰值、削波、立体声相关、频谱平衡偏差），查过了才给 👤听；「好不好听」只有 👤的耳朵能判，我听不见。

## 七、借来的规矩（外部参考里值得照抄的）
- mgaudio：**同步点**（每个声音带一个 sync 点：起音 / 冲击 / 上扬的终点；放声音 = 把同步点放到事件时刻，不手算提前量）；**网格锚在 drop**（第 0 小节 = drop）；所有音效先按响度归一化，增益只表达意图。
- pdoom-video：**每帧 = 时间 t 的纯函数**，预览和导出走同一份代码；剪辑锚在内容（歌词、场景）上再吸附到拍；母题全片共用一个文件。
- claudia.gallery：付费账本、构建和审核分开、词级歌词门控。
- 我们自己的：**样片不覆盖、按版本命名**；声音和画面分开时写明「听的」和「看的」（词表 v1 踩过：延迟嵌入的立体声外放会抵消第 2、6、10… 次泛音）。
