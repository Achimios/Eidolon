先找手感（不录）

  1. 按 Space 播放，循环一直转
  2. 在 A S D F 那排乱按：锁了调，不会错音
  3. ↑ / ↓ 换八度，左边换层（贝斯、铺底……）

录一段

  1. 按 `：先数一小节，然后边转边叠
  2. 再按 ` 停 → 弹出 4 个版本
  3. ← / → 听，Enter 用，不满意 Ctrl+Z

哼唱

  1. 戴耳机；第一次先「校准延迟」
  2. 选「哼唱」层，开麦，按 ` 录
  3. 或者：把一段干净的单人声 wav 拖到哼唱层上

存

  1. Ctrl+S：存成新版本，从不覆盖
  2. 觉得这一版可以了 →「定稿」
